Módulo 70 – Master Skill Tree e Combos de Classe

Documenta o sistema de Master Skill Tree e combos do código legado em C++, separando enums, requisitos e cálculos, e descreve a adaptação 1:1 em Unreal Engine 5 com DataTables, Blueprints e UI detalhada.

Estruturas e Enums do Legado

Master Skill Tree
  • MasterSkillTree.cpp: listas g_MasterSkillTreeData e g_MasterSkillTreeNode com Index, SkillID, ReqPoint, Parent, MaxLevel, Penalty e Class (bitmask por personagem).
  • Pacotes: 0x30F/0x30E para request/confirm de alocação; 0x30C para reset; 0x30D para carregar árvore.
  • Enums: eMLDL_CLASS, eMGL_CLASS etc. controlam quais nós aparecem. eMST_OPTION lista bônus (dano skill, mana, redução de delay, novas skills).
Combos de Classe
  • Combo.cpp: verifica sequência de skills (ex.: Twisting Slash → Rageful Blow → Death Stab para BK) dentro de janela de tempo (COMBO_AGE_TIME) e multiplica dano com gComboDamage.
  • Buffers/sons: usa enum de som DS_PLAY_SOUND::SKILL_COMBO e efeitos de hit extra. Flags de anti-cheat impedem repetição fora do intervalo.
  • UI: client envia GCUseAttackSkill com sequência, servidor confirma via 0x1E (target/hit/dano) e atualiza buffs.

Recriação em UE5 – Dados e Persistência

  • Crie uma DataTable DT_MasterSkillNodes (struct FMasterSkillNodeRow) com campos: NodeID (int), SkillID (int), ParentIDs (TArray<int>), ReqPoints, MaxLevel, Penalty, AllowedClasses (bitmask), EffectType (enum), ValuePerLevel, FX (Niagara/System) e Sound.
  • Crie tabela DT_ComboChains com Class, Sequence (TArray<int> de SkillID), WindowSeconds, DamageMultiplier, Sound, FX.
  • Adicione ao BP_MuPlayerState arrays replicados MasterSkillPoints e MasterSkillLevels (Map <NodeID, Level>). Persista via BP_ServerPersistence na seção /characters/{guid}/masterskills.
  • Mapeie os enums legados em DT_SkillCatalog (SkillID → nome, animação, efeitos, custo) já usado em outros módulos; inclua entradas de skills de Master Tree (ex.: Gigantic Storm, Mana Shield Mastery).

Blueprints – Servidor

  • No BP_GameServer, crie função ServerAllocateMasterSkill (Input: PlayerState, NodeID, SpendPoints) com Switch on Int para validar ReqPoints, ParentIDs completos e Class permitido. Use Branch → ForEachLoop (ParentIDs) → Map Find (MasterSkillLevels).
  • Ao aplicar, incremente MasterSkillLevels, deduza pontos livres e aplique efeitos: use Select por EffectType (AddFloat to BonusDamage, ReduceCooldown, UnlockSkill adicionando ao UnlockedSkills replicado).
  • Implemente ServerResetMasterSkill (pacote 0x30C equivalente) com reembolso, e dispare Multicast para atualizar UI.
  • Para combos, adicione componente BP_ComboTracker ao personagem: em Event OnSkillCasted, use Set Timer by Event para limpar sequência, Append Array de SkillIDs e compare com DT_ComboChains. Em sucesso, aplique multiplicador no dano final antes de replicar HitResult.

Blueprints – Cliente/UI

  • Crie widget WBP_MasterSkillTree (Canvas 1280×720). Adicione ScrollBox 1120×640 ancorado centro, e dentro um WrapBox para nós. Cada nó usa widget WBP_MasterSkillNode (160×120) com Image do ícone, TextBlock para nível Lv X/Y e Button “+”.
  • Posicionamento 1:1: para classes DK/SM/ELF, organize três colunas (x=40/240/440, y escalonado a cada 140 px). Para DL/RF/GK, segunda linha (x=640/840/1040). Use linhas BP_SplineConnector entre pais e filhos (cor branca; laranja quando desbloqueado).
  • Bind do botão “+”: em WBP_MasterSkillTree, no evento OnClicked do nó, chame ServerAllocateMasterSkill via BP_MuPlayerController; mostre Widget Interaction “Alocando...” e desabilite botão até resposta.
  • Feedback visual 1:1: adicione NiagaraComponent “UnlockFx” (glow azul) no Overlay do nó, e AudioComponent com SoundCue_MasterUnlock mapeado do enum de som de skill tree.
  • Para combos, crie widget WBP_ComboHint (300×80, âncora canto inferior direito x=940,y=620). Mostre sequência esperada (ícones lado a lado) e barra de tempo (progress bar) vinculada ao WindowSeconds. Atualize via evento OnComboProgress do BP_ComboTracker.

Checagens de Fidelidade 1:1

  • Valores de ReqPoints, Penalty e MaxLevel idênticos aos de MasterSkillTree.xml/bmd e arrays do cliente.
  • Sequência e janela dos combos iguais aos do Combo.cpp; dano final reproduz gComboDamage (inclua clamp para PK/PvE se existir no legado).
  • UI: coordenadas, tamanho de ícones e cores dos conectores seguem layout clássico; tooltips exibem nome/descrição/valor por nível e custo de mana conforme DT_SkillCatalog.
  • Persistência: alocações salvas no logout, restauração na entrada e reenvio de habilidades desbloqueadas para hotbar.
