Módulo 15 – Arca Battle (Obeliscos e Estados)

Cobrimos o evento Arca Battle do GameServer, incluindo pacotes, leitura de script, máquina de estados e como espelhar o ciclo em Unreal Engine 5.

Pré-requisitos

  • Concluir módulos 6, 8 e 12 para entender timers do servidor, roteamento de pacotes e movimentação de monstros.
  • Noções de sistemas de estado em UE5 (GameMode, GameState) e timers em FTimerManager.
  • Capacidade de ler arquivos de configuração e popular DataAssets em UE5.

Leitura de configuração – CArcaBattle::Load
📘 O Que é?

Rotina que consome arquivo script e popula horários e dados de obeliscos/aura.

🎯 Para Que Serve?

Carrega programações do evento e posições/vida dos obeliscos antes de iniciar a máquina de estados.

💻 Como Funciona?

void CArcaBattle::Load(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript == 0) { ErrorMessageBox(MEM_SCRIPT_ALLOC_ERROR,path); return; }
    if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); delete lpMemScript; return; }
    this->m_ArcaBattleStartTime.clear();
    while(true) {
        if(lpMemScript->GetToken() == TOKEN_END) break;
        int section = lpMemScript->GetNumber();
        while(true) {
            if(section == 0) { /* lê datas */ info.State = lpMemScript->GetNumber(); ... this->m_ArcaBattleStartTime.push_back(info); }
            else if(section == 1) { /* obelisco */ info.Group = lpMemScript->GetNumber(); info.MonsterClass = lpMemScript->GetAsNumber(); ... this->m_ObeliskInfo[info.Group] = info; }
            else if(section == 2) { /* aura */ info.Group = lpMemScript->GetNumber(); info.Index = lpMemScript->GetAsNumber(); ... this->m_ObeliskInfo[info.Group].AuraInfo[info.Index] = info; }
            else { break; }
        }
    }
    delete lpMemScript;
}

Máquina de estados e loop – CArcaBattle::MainProc e ProcState_*
📘 O Que é?

Loop de 1 segundo que controla a progressão do evento pelas fases (BLANK, EMPTY, SIGN, READY, PARTY, START, CLOSE, CLEAN, CLEAR).

🎯 Para Que Serve?

Sincroniza avisos, respawn de obeliscos, envio de vida/estado e transições de fase conforme contagem regressiva.

💻 Como Funciona?

void CArcaBattle::MainProc() {
    if((GetTickCount()-this->m_TickCount) >= 1000) {
        this->m_TickCount = GetTickCount();
        this->m_RemainTime = (int)difftime(this->m_TargetTime,time(0));
        switch(this->m_State) {
            case AB_STATE_EMPTY: this->ProcState_EMPTY(); break;
            case AB_STATE_SIGN1: this->ProcState_SIGN1(); break;
            case AB_STATE_SIGN2: this->ProcState_SIGN2(); break;
            case AB_STATE_READY: this->ProcState_READY(); break;
            case AB_STATE_PARTY: this->ProcState_PARTY(); break;
            case AB_STATE_START: this->ProcState_START(); break;
            case AB_STATE_CLOSE: this->ProcState_CLOSE(); break;
            case AB_STATE_CLEAN: this->ProcState_CLEAN(); break;
            case AB_STATE_CLEAR: this->ProcState_CLEAR(); break;
        }
    }
}

void CArcaBattle::ProcState_START() {
    this->ChkAuraUserHover();
    this->GCArcaBattleObeliskLifeSend();
    this->GCArcaBattleObeliskStateSend();
    this->RegenObelisk();
    if(this->m_RemainTime <= 0) { gNotice.GCNoticeSendToAll(0,0,0,0,0,0,"[ArcaBattle] CLOSE"); SetState(AB_STATE_CLOSE); }
}

Implementação em Unreal Engine 5

  • Estruturas de pacote: criar USTRUCT equivalentes e serializar via sockets ou VaRest/HTTP para um microserviço Node.js que persiste inscrições em SQL.
  • Configuração: armazenar datas e obeliscos em UDataAsset (ex.: UArcaBattleConfig) carregado no AGameModeBase no BeginPlay.
  • Máquina de estados: usar AGameStateBase com um FTimerHandle de 1s, enumerando estados EArcaBattleState e replicando via OnRep.
  • Manipuladores: expor UFUNCTION(Server) em um APlayerController para registrar guilds/marcas, chamando o serviço Node.js com VaRest para validar e atualizar SQL.

Passo a Passo em Unreal Engine 5

  1. Criar um UArcaBattleConfig com arrays de datas e obeliscos (grupo, mapa, coord, vida) e popular a partir de CSV/JSON.
  2. No AGameModeBase personalizado, carregar o UArcaBattleConfig e iniciar um timer de 1s que chama TickArcaBattle().
  3. Implementar TickArcaBattle replicando a lógica de MainProc: diminuir RemainTime, disparar eventos multicast para UI e spawn de obeliscos (AActor com componente de vida).
  4. Criar AArcaObelisk derivado de AActor com componente de colisão e atributo ObeliskAttribute; replicar estado/vida para clientes.
  5. No APlayerController, adicionar RPCs ServerRegisterGuild e ServerRegisterMark; cada RPC chama um endpoint VaRest → Node.js → SQL para gravar inscrição e retorna resultado para UI.
  6. Usar UUserWidget para painéis de inscrição e monitoramento; bindar a eventos OnStateChanged, OnObeliskUpdated disparados pelo AGameStateBase.
  7. Replicar avisos globais via Multicast e áudio, seguindo as transições BLANK→EMPTY→...→CLEAR.

Checklist Final

  • Config de datas e obeliscos carregada no GameMode.
  • Timer de 1s alternando estados e replicando para clientes.
  • Obeliscos spawnados com atributos/aura corretos e atualização de vida.
  • Registro de guild/master e marcas operando via RPC + VaRest/Node.js + SQL.
  • UI mostra avisos e fases conforme o loop original.

Guia Blueprint ultra detalhado (iniciante)

Objetivo: recriar o evento Arca Battle somente com Blueprints + VaRest, sem exigir código C++ do aluno.

1) Preparação de assets

  • No Content Drawer, crie DataAsset » ArcaBattleConfig (Base: PrimaryDataAsset) com arrays: Datas (DateTime), Obeliscos (Struct: Mapa, X, Y, Vida, Aura, GuildOwner).
  • Adicione sons SFX_EventStart e SFX_ObeliskUnderAttack; partículas para aura (azul/vermelha) em /VFX/Arca.
  • Monte um Blueprint Actor BP_ArcaObelisk com StaticMesh central, Sphere Collision (raio 180), Widget 3D para barra de vida.
  • Crie Widget WBP_ArcaPanel (1920x1080):
    • Caixa superior (X=640, Y=40, W=640, H=120) para fase/tempo.
    • Grid de obeliscos (colunas 2x2) com barras de HP (W=280, H=24) e cor da aura.
    • Botão "Registrar Guild" (X=80, Y=880, W=260, H=60) + label de erro (vermelho) logo abaixo.

2) Blueprint do GameMode/GameState

  1. Duplique seu GameMode e GameState atuais para GM_ArcaBattle e GS_ArcaBattle.
  2. No GS_ArcaBattle, crie Enum EArcaState (BLANK, EMPTY, PLAYING, END, CLEAR) e variáveis replicadas: CurrentState, RemainingSeconds, ObeliskInfos (array de struct com Vida/Aura/GuildOwner).
  3. Event BeginPlay (server): "Get DataTable Row" ou "Get Primary Asset" → preenche ObeliskInfos e seta RemainingSeconds baseado no próximo horário do DataAsset.
  4. Use Set Timer by Function Name (Rate 1.0, Looping) chamando função TickArcaBattle no GameState (executes on server; marcada como Run on Server via Authority check).
  5. Em TickArcaBattle: decrementa RemainingSeconds; quando chega a 0, avança estado: BLANK→EMPTY (spawn obeliscos), EMPTY→PLAYING (habilita dano), PLAYING→END (fecha inscrição), END→CLEAR (limpa obeliscos) e recomeça o ciclo.
  6. Para spawn: ForEach ObeliskInfos → SpawnActor BP_ArcaObelisk na coordenada (X=Obelisk.X, Y=Obelisk.Y, Z=120) com Authority Only. Guarde referência num array replicado SpawnedObelisks.

3) Fluxo UI e botões

  1. No APlayerController, Event BeginPlay (client): Create Widget WBP_ArcaPanel → Add to Viewport → define Input Mode Game and UI.
  2. Bind no WBP_ArcaPanel:
    • Texto de fase: GS_ArcaBattle.CurrentState → Switch on Enum → converte para string.
    • Timer: RemainingSeconds formatado MM:SS (use Divide int 60 e Modulo).
    • Grid de obeliscos: Construct → cria widgets filhos para cada ObeliskInfos; OnRep_ObeliskInfos atualiza barras de HP (Set Percent) e cores.
  3. Botão Registrar: OnClicked → chama função local RequestRegisterGuild (veja seção VaRest) e desativa o botão enquanto espera resposta.
  4. Alertas: em OnRep_CurrentState (client) toca SFX/mostra anúncio em tela cheia quando entra em PLAYING e CLEAR.

4) VaRest + SQL (microserviço)

  • Endpoint POST /arca/register (body: account, guild, markCode) grava em tabela arca_registrations (columns: id, account, guild, markCode, timestamp).
  • No PlayerController (client), crie função RequestRegisterGuild:
    1. VaRestRequestJSON → Set URL http://127.0.0.1:3000/arca/register.
    2. Set Verb POST, Set Request Object com campos.
    3. Bind Event to OnRequestComplete → no sucesso, exibir mensagem verde e reabilitar botão; no erro, mensagem vermelha.
  • No servidor Blueprint (Authority), quando um obelisco perde vida: OnComponentBeginOverlap → se atacante é de guild X, atualize GuildOwner na struct e faça PATCH /arca/obelisk salvando dono/HP.

5) Debug visual

  • Adicione comando console ToggleArcaDebug: mostra um WBP_ArcaDebug com lista de timers e HP.
  • No BP_ArcaObelisk, habilite Draw Debug Sphere (raio 180, cor ciano) em BeginPlay e quando HP mudar.
  • Checklist final para o aluno: conseguir registrar guild, ver HUD mudar estados em 5 min, causar dano em obelisco e observar cor da aura trocando.
