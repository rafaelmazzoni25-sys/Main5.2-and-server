Módulo 66 – Auditoria de UI e Layouts 1:1

Inventário completo das telas do cliente legado (CNewUIManager) com nomes de widgets, caminhos, anchors e coordenadas para reconstrução 1:1 em Unreal Engine 5. Use como checklist para garantir que cada módulo que toca UI indique exatamente como montar a tela.

Contexto do Código Original

  • Gerenciador: CNewUIManager registra cada janela via IDs como INTERFACE_LOGIN, INTERFACE_INVENTORY, INTERFACE_TRADE, etc., definidos em UIControls.h e UICustomWindow.h.
  • Texturas: atlases referenciados via enums IMAGE_LOGIN, IMAGE_INVENTORY, BITMAP_SHOP e companhias. Os índices mapeiam para coordenadas de UV dentro dos arquivos OZT/OZP.
  • Posicionamento: a maioria das telas usa coordenadas absolutas em 640x480 ou 800x600. Este módulo fornece a equivalência em 1920x1080 para UE5 preservando proporção (scale boxes).
  • Eventos: hotkeys e mensagens de rede chamam funções de abertura (OpenInventory, OpenPersonalShop, OpenOptionWindow), que disparam renderização no loop principal.

Passo a Passo UE5 – Reforço de Layout

  1. Escala e âncoras: para cada widget, adicione um ScaleBox fixo em 1920x1080 com Stretch = ScaleToFit. Dentro dele, use Canvas Panel e posicione elementos pelos valores fornecidos.
  2. Nomes de arquivos: mantenha a convenção WBP_<Tela> em /Game/UI/<Subpasta>. Ex.: /Game/UI/Login/WBP_Login, /Game/UI/Inventory/WBP_Inventory, /Game/UI/Events/WBP_EventTimer.
  3. Bindings: crie BP_UIRouter (ActorComponent no PlayerController) com refs para todos os widgets principais. Exponha funções ShowInventory, ShowShop, ShowWarehouse, ShowEventHUD que fazem Create Widget → Add to Viewport se não existir.
  4. Input: configure Enhanced Input para hotkeys do legado (I inventário, V shop pessoal, B commandos, U party). Cada ação chama o método correspondente no BP_UIRouter.
  5. Assets convertidos: ao importar texturas OZ*/DDS, use Texture Group UI e Compression Settings = UserInterface2D (RGBA). Para slots/frames, gere materiais com canal alfa preservado.
  6. Estados ativos: mantenha variáveis bInventoryOpen, bShopOpen, bTradeOpen no router para evitar múltiplas instâncias. Use Set Input Mode Game and UI quando qualquer UI de loja/trade estiver visível.

Depuração Visual e QA

  • Ative Widget Reflector e verifique que cada widget está em ZOrder esperado (HUD 0-5, timers 10, modais 20+).
  • Use Stat UnitGraph e Stat Slate para checar draw calls; telas devem manter < 2 ms em 1080p.
  • Compare capturas do cliente legado com capturas da UE5 usando sobreposição (ex.: Photoshop com opacidade 50%). Ajuste anchors até alinhar.
  • Salve preset de cores e fontes em /Game/UI/Style/DA_UIStyle para garantir consistência entre módulos.
