Inicialização da Chaos Box – CChaosBox::ChaosBoxInit
📘 O Que é?

Limpa todos os slots da Chaos Box e mapa de ocupação.

🎯 Para Que Serve?

Garante que cada tentativa de mix começa com slots válidos e índices zerados.

💻 Como Funciona?

void CChaosBox::ChaosBoxInit(LPOBJ lpObj) {
    for(int n=0;n < CHAOS_BOX_SIZE;n++) {
        lpObj->ChaosBox[n].Clear();
        lpObj->ChaosBoxMap[n] = 0xFF;
    }
}

Cálculo de taxa com Talisman – CChaosBox::GetTalismanOfLuckRate
📘 O Que é?

Acumula durabilidade de Talismans of Luck na Chaos Box para aumentar a taxa de sucesso.

🎯 Para Que Serve?

Aplica bônus de sorte proporcional à quantidade/durabilidade de talismãs, respeitando limite máximo.

💻 Como Funciona?

bool CChaosBox::GetTalismanOfLuckRate(LPOBJ lpObj,int* rate) {
    int count = 0;
    for(int n=0;n < CHAOS_BOX_SIZE;n++) {
        if(lpObj->ChaosBox[n].IsItem() == 0) continue;
        if(lpObj->ChaosBox[n].m_Index == GET_ITEM(14,53)) {
            count += (int)lpObj->ChaosBox[n].m_Durability;
        }
    }
    (*rate) += count;
    return ((count>MAX_TALISMAN_OF_LUCK)?0:1);
}

Mixagem base – CChaosBox::ChaosItemMix
📘 O Que é?

Processa itens inseridos, calcula custo, taxa e decide sucesso/falha.

🎯 Para Que Serve?

Implementa a regra padrão de Chaos Mix (chaos + itens de nível ≥4 com opção), com fallback para mensagens de erro.

💻 Como Funciona?

void CChaosBox::ChaosItemMix(LPOBJ lpObj) {
    int ChaosCount = 0, ItemCount = 0, ItemMoney = 0;
    for(int n=0;n < CHAOS_BOX_SIZE;n++) {
        if(lpObj->ChaosBox[n].IsItem() == 0) continue;
        if(lpObj->ChaosBox[n].m_Index == GET_ITEM(12,15)) { ChaosCount++; lpObj->ChaosBox[n].OldValue(); ItemMoney += lpObj->ChaosBox[n].m_OldBuyMoney; }
        else if(lpObj->ChaosBox[n].m_Index == GET_ITEM(14,13) || lpObj->ChaosBox[n].m_Index == GET_ITEM(14,14)) { ItemCount++; lpObj->ChaosBox[n].OldValue(); ItemMoney += lpObj->ChaosBox[n].m_OldBuyMoney; }
        else if(lpObj->ChaosBox[n].m_Level >= 4 && lpObj->ChaosBox[n].m_Option3 >= 1) { ItemCount++; ItemMoney += lpObj->ChaosBox[n].m_BuyMoney; }
    }
    if(ChaosCount == 0 || ItemCount == 0) { this->GCChaosMixSend(lpObj->Index,7,0); return; }
    if(gServerInfo.m_ChaosItemMixRate[lpObj->AccountLevel] == -1) lpObj->ChaosSuccessRate = (ItemMoney/20000);
    else lpObj->ChaosSuccessRate = gServerInfo.m_ChaosItemMixRate[lpObj->AccountLevel];
    if(this->GetTalismanOfLuckRate(lpObj,&lpObj->ChaosSuccessRate) == 0) { this->GCChaosMixSend(lpObj->Index,240,0); return; }
}

Upgrade +10 a +15 – CChaosBox::PlusItemLevelMix
📘 O Que é?

Receita avançada da Chaos Machine que permite subir itens acima do +9 usando combinação de Chaos, Bless, Soul e Life.

🎯 Para Que Serve?

Replica o fluxo padrão do Mu original para melhorar itens além do limite das joias comuns.

💻 Como Funciona?

A função varre os slots da Chaos Box e valida: 1 item equipável nível ≥9, 1 Chaos, 1 Bless, 1 Soul e 1 Life. Calcula taxa base via gServerInfo.m_PlusItemLevelMixRate e aplica bônus de Talisman of Luck. Sucesso incrementa m_Level do item; falha destrói o item principal (joias são consumidas).

int iChaos = this->GetChaosItemCount(lpObj);
if(iChaos != 1 || this->GetItemPlus10MixCheck(lpObj) == 0) { this->GCChaosMixSend(lpObj->Index,7,0); return; }
lpObj->ChaosSuccessRate = gServerInfo.m_PlusItemLevelMixRate[lpObj->AccountLevel];
this->GetTalismanOfLuckRate(lpObj,&lpObj->ChaosSuccessRate);
if( (rand()%100) < lpObj->ChaosSuccessRate ) this->ChaosMixPlusItemLevelSuccess(lpObj);
else this->ChaosMixPlusItemLevelFail(lpObj);

⏱️ Quando é Executado?

Quando o jogador coloca item + joias + Chaos na máquina e confirma o mix (opcode 0x86 com type=0x13).

Implementação em Unreal Engine 5

  • Representar a Chaos Box como um UInventoryComponent dedicado em APlayerState ou APlayerController, com array replicado de slots.
  • Calcular taxas em C++ ou no backend: enviar composição via VaRest para Node.js registrar tentativa e retornar sucesso/falha, aplicando bônus de talismãs.
  • Usar UUserWidget para UI de mix com validações (mínimo 1 chaos + item elegível).
  • Persistir logs/resultados em SQL pelo Node.js para auditoria.
  • Receita +10 a +15: adicione ramo Request.Type == PlusItemLevel no RPC de mix. No servidor UE5, valide a presença de 1 item em Slot_1 com Level >= 9 e as joias (Chaos/Bless/Soul/Life) nos demais slots. Consulte ChaosMixRates_DT.PlusMixRate e bônus de talismã para definir a chance; sucesso: Item.Level++; falha: destrua item e joias.
  • Efeito visual/áudio: após sucesso, dispare Multicast MC_OnMixSuccess que aciona Spawn Emitter at Location (niagara NS_ItemUpgrade) e som SFX_ChaosSuccess. Em falha, use NS_ChaosFail e SFX_ChaosFail.

Passo a Passo em Unreal Engine 5

  1. Criar UChaosBoxComponent com tamanho fixo, métodos ResetSlots() e ServerStartMix() (RPC).
  2. Em ResetSlots(), limpar os slots replicados semelhante a ChaosBoxInit.
  3. Na UI, ao clicar “Mix”, coletar itens elegíveis e chamar ServerStartMix; o servidor UE5 envia payload via VaRest para Node.js calcular taxa (incluindo durabilidade de talismãs) e resposta de sucesso.
  4. No retorno, aplicar consumo/resultado dos itens no componente de inventário e replicar para o cliente.
  5. Adicionar RPC ServerCloseMix para limpar/fechar a janela, espelhando o pacote 0x87.

Checklist Final

  • Slots da Chaos Box sincronizados e resetáveis.
  • Validação de itens e bônus de talismãs aplicada no cálculo de taxa.
  • Fluxo de mix acionado via UI → RPC → VaRest/Node.js → SQL com resultado replicado.
  • Logs de tentativa/sucesso armazenados para auditoria.

Guia Blueprint ultra detalhado (iniciante)

Instrui o aluno clique a clique para montar a Chaos Machine somente com Blueprints + VaRest.

1) Montagem visual

  • Crie Widget WBP_ChaosBox (800x640):
    • Grid 4x4 de slots (cada 64x64) alinhado em X=60, Y=80; nomeie Slot_1..Slot_16.
    • Botão "Mix" (X=620, Y=520, W=120, H=50), botão "Limpar" (X=480, Y=520, W=120, H=50).
    • Texto de taxa (X=60, Y=20, W=300) e log de resultado (TextBox readonly em X=60, Y=580, W=680, H=40).
  • Actor BP_ChaosMachine: StaticMesh da máquina, Box Collision (200x200x150), WidgetComponent para mostrar taxa acima da máquina.

2) Componentes em Blueprint

  1. No Character, adicione BP_ChaosBoxComponent (Scene Component) com variáveis replicadas: Slots (Array de Struct {ItemID, Level, Durability, HasTalisman}), IsOpen (bool).
  2. Função OpenChaosBox (Client): Create Widget WBP_ChaosBox → Add to Viewport → seta IsOpen=true.
  3. Função ResetSlots (Server, Reliable): limpa array, chama OnRep_Slots no client para limpar UI.
  4. Função ServerStartMix (Server, Reliable): lê Slots, monta JSON e chama VaRest (veja abaixo); enquanto processa, desativa botões.

3) Preenchendo slots via drag & drop

  1. Em cada Slot_X, implemente OnDrop: recebe item do inventário, chama ServerPlaceItemInSlot(Index, ItemData) (RPC Server).
  2. No servidor, valide se o item está no inventário e se atende aos requisitos de mix (ex.: Joia do Caos). Se ok, remove do inventário, grava na posição do array e dispara OnRep_Slots.
  3. OnRep_Slots (client) atualiza o ícone/tooltip do slot correspondente.

4) VaRest + SQL para cálculo

  • Endpoint POST /chaos/mix recebe JSON {slots:[{itemId,level,durability,talisman}]}. O Node.js aplica a fórmula da taxa (inclui durabilidade do talismã) e retorna {success, newItemId, log} e grava tabela chaos_logs.
  • No ServerStartMix (Authority):
    1. VaRestRequestJSON → URL http://127.0.0.1:3000/chaos/mix → Verb POST.
    2. OnSuccess: se success=true, adiciona novo item ao inventário e limpa slots; se falso, apenas limpa slots e mostra log.
    3. OnFail: reverte itens ao inventário e mostra mensagem de erro vermelha.

5) Feedback e debug

  • Adicione SFX "Forge_Start" ao clicar Mix, "Forge_Success"/"Forge_Fail" conforme resultado.
  • Exiba barra de progresso (X=60,Y=460,W=680) durante a requisição VaRest (Timeline de 1s) para sinalizar processamento.
  • Checklist do aluno: arrastar item, clicar Mix, ver barra animar, receber log verde/vermelho e inventário refletir consumo/resultado.
