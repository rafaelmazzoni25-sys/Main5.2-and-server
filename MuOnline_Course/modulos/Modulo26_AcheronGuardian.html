Conceitos do Código Original

CGAcheronEnterRecv – Validação de item 13,146 e teleporte
📘 O Que é?

Handler do pacote 0xF8 0x21 que exige o item 13,146 (entrada Acheron), consome-o e move o jogador para o gate 417.

void CGAcheronEnterRecv(int aIndex) {
    LPOBJ lpObj = &gObj[aIndex];
    if(gObjIsConnectedGP(aIndex) == 0) { return; }
    PMSG_ACHERON_ENTER_SEND pMsg; pMsg.header.set(0xF8,0x21,sizeof(pMsg));
    if(gItemManager.GetInventoryItemCount(lpObj,GET_ITEM(13,146),0) == 0) {
        pMsg.result = 1; DataSend(aIndex,(BYTE*)&pMsg,pMsg.header.size); return;
    }
    gItemManager.DeleteInventoryItemCount(lpObj,GET_ITEM(13,146),0,1);
    gObjMoveGate(aIndex,417);
}

🎯 Para Que Serve?

Garante que somente jogadores com o item de acesso possam entrar em Acheron; em caso de ausência, retorna código de falha para o cliente.

💻 Como Funciona?

Confere conexão válida, instancia mensagem de resposta, verifica quantidade do item 13,146; se faltar, envia result=1. Caso contrário, remove uma unidade do inventário e chama gObjMoveGate com o gate 417.

⏱️ Quando é Executado?

Ao receber o pacote de entrada elemental; Protocol.cpp mapeia a mensagem e chama CGAcheronEnterRecv diretamente.

Implementação em Unreal Engine 5

  • Estruturas equivalentes: APlayerController com RPC ServerRequestEnterAcheron; componente de inventário replicado para contar/remover item; AGameModeBase opcional para validar regras globais.
  • Crie um USTRUCT para representar o item de entrada (ID 13,146) e expose uma função bool ConsumeAcheronTicket() no componente de inventário.
  • Ao receber o pedido no servidor, chame ConsumeAcheronTicket; se falhar, execute ClientNotifyAcheronResult(false). Se tiver ticket, chame ClientTravel ou ServerTravel para o mapa Acheron e posicione na localização do gate.
  • Registre consumo e teleporte via VaRest em endpoint Node.js/SQL para auditoria e estatísticas.

Passo a Passo em Unreal Engine 5

  1. Adicionar um enumerador/struct de itens com o código 13,146 no inventário replicado.
  2. Implementar ServerRequestEnterAcheron() no PlayerController, chamando o componente de inventário para verificar quantidade.
  3. Se houver ticket, remover 1 unidade e chamar ClientTravel para o mapa Acheron (ou TeleportTo se o mapa já estiver carregado).
  4. Enviar RPC cliente ClientNotifyAcheronResult(bool bSuccess) para atualizar a UI.
  5. Usar VaRest para postar o resultado de entrada (sucesso/falha) no backend Node.js/SQL.
  6. Testar cenários: sem item (deve falhar), com item (deve consumir e teleportar), desconexão rápida (não deve consumir).

Checklist Final

  • Pedido de entrada verifica conexão e inventário replicado.
  • Item 13,146 é consumido uma vez por tentativa bem-sucedida.
  • Teleporte para o mapa Acheron ocorre na posição equivalente ao gate 417.
  • UI recebe notificação de falha/sucesso e backend Node.js/SQL registra o evento via VaRest.
