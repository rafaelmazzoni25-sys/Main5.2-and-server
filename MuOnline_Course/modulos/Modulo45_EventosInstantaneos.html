Módulo 45 – Eventos Instantâneos (Quickly e Run and Catch)

Documenta o fluxo dos eventos rápidos acionados por GMs (Quickly e Run and Catch), cobrindo timers, avisos e distribuição de prêmios, com a respectiva adaptação para Unreal Engine 5.

Pré-requisitos

  • Módulo 1 – Arquitetura Geral (loop de eventos em gObjEventRunProc).
  • Módulo 6 – Eventos de Servidor (estrutura de notices e rewards).
  • Módulo 9 – Persistência/DataServer (para salvar moedas via GDSetCoin/VaRest).

Conceitos do Código Original

Timer e avisos do Quickly – CEventQuickly::MainProc
📘 O Que é?

Loop que decrementa o tempo restante, envia avisos globais e finaliza o evento quando o NPC expira.

void CEventQuickly::MainProc() {
  DWORD elapsed = GetTickCount()-this->m_TickCount;
  if(elapsed < 1000) return;
  this->m_TickCount = GetTickCount();
  if(this->m_RemainTime > 0) {
    int minutes = this->m_RemainTime/60;
    if((this->m_RemainTime%60) == 0) minutes--;
    if(this->MinutesLeft != minutes) {
      this->MinutesLeft = minutes;
      gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(661),(MinutesLeft+1));
    }
    if(this->m_RemainTime <= 5) { gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(662),m_RemainTime); }
    this->m_RemainTime--;
    if(this->m_RemainTime <= 0) {
      gObjDel(this->m_NpcIndex);
      this->Clear();
      gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(664));
      LogAdd(LOG_EVENT,"[QUICKLY EVENT] Finish");
    }
  }
}

🎯 Para Que Serve?

Controla a contagem regressiva do evento Quickly, garantindo avisos de tempo restante e limpando o NPC ao término.

💻 Como Funciona?

Executado a cada segundo; quando o tempo muda de minuto ou entra nos últimos 5 segundos, dispara notices. Ao chegar a zero, remove o NPC e registra log.

if(this->m_RemainTime <= 0) {
  gObjDel(this->m_NpcIndex);
  this->Clear();
  gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(664));
}

Spawn e início do Quickly – CEventQuickly::CommandEventQuickly
📘 O Que é?

Comando de GM que cria o NPC do evento em um mapa/posição e define o tempo total do desafio.

void CEventQuickly::CommandEventQuickly(LPOBJ lpObj,char* arg) {
  if(gServerInfo.m_QuicklyEvent == 0) return;
  if(gGameMaster.CheckGameMasterLevel(lpObj,1) == 0) return;
  if (this->m_RemainTime > 0) { gObjDel(this->m_NpcIndex); this->Clear(); ... }
  int map = gCommandManager.GetNumber(arg,0);
  int x = gCommandManager.GetNumber(arg,1);
  int y = gCommandManager.GetNumber(arg,2);
  int time = gCommandManager.GetNumber(arg,3);
  if(map < 0 || x <= 0 || y <= 0) { map = rand() % 4; gObjGetRandomFreeLocation(map,&x,&y,255,255,50); }
  int index = gObjAddMonster(map);
  LPOBJ lpNPC = &gObj[index];
  lpNPC->X = x; lpNPC->Y = y; lpNPC->Dir = 1; lpNPC->Map = map;
  if(gObjSetMonster(index,465) == 0) { gObjDel(index); return; }
  this->m_NpcIndex = index;
  gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(660),MapName);
  gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(665),x,y);
  this->m_RemainTime = time*60;
  LogAdd(LOG_EVENT,"[QUICKLY EVENT] Start");
}

🎯 Para Que Serve?

Permite ao GM lançar rapidamente o evento com spawn de NPC, avisos de localização e duração configurável.

💻 Como Funciona?

Lê parâmetros do chat, ajusta mapa/coords aleatórios se necessário, cria o NPC 465, grava o índice para remoção futura e inicia o cronômetro.

int index = gObjAddMonster(map);
if(gObjSetMonster(index,465) == 0) { gObjDel(index); return; }
this->m_RemainTime = time*60;
LogAdd(LOG_EVENT,"[QUICKLY EVENT] Start");

Encerramento e recompensa do Quickly – CEventQuickly::ClickNPC
📘 O Que é?

Handler acionado quando o jogador clica no NPC, encerrando o evento, tocando fogos e atribuindo moedas automáticas.

🎯 Para Que Serve?

Define o vencedor, dispara efeitos visuais e envia moedas configuradas via GDSetCoinSend.

💻 Como Funciona?

Remove o NPC, limpa estado, dispara notice global e envia recompensa se configurada.

void CEventQuickly::ClickNPC(LPOBJ lpObj) {
  gObjDel(this->m_NpcIndex);
  this->Clear();
  GCFireworksSend(lpObj,lpObj->X,lpObj->Y);
  gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(663),lpObj->Name);
  if (gServerInfo.m_QuicklyEventAutoReward1 > 0 || ...) {
    GDSetCoinSend(lpObj->Index, gServerInfo.m_QuicklyEventAutoReward1, ... ,"QuicklyEvent");
  }
  LogAdd(LOG_EVENT,"[QUICKLY EVENT] Finish (Winner:%s)",lpObj->Name);
}

Controle do Run and Catch – CEventRunAndCatch::CommandEventRunAndCatch/MainProc/EventRunAndCatchHit
📘 O Que é?

Conjunto de rotinas que abre inscrições, inicia o evento, acompanha tempo e detecta captura/vencedor.

🎯 Para Que Serve?

Permite ao GM iniciar um mini pega-pega: jogadores se inscrevem, são teleportados e, ao serem atingidos pelo GM, podem ser eliminados ou ganhar o evento.

💻 Como Funciona?

{ gNotice.GCNoticeSendToAll(...); this->m_EventRunAndCatchActive = 1; this->m_EventRunAndCatchEnter = 0; }

Implementação em Unreal Engine 5

Equivalências

  • Gestão do evento: AGameState personalizado com variáveis replicadas (RemainingTime, IsActive, Winner).
  • NPC Quickly: AActor simples com UInteractionComponent para clique.
  • Inscrição/teleporte: RPCs em APlayerController + UGameplayStatics::TeleportTo ou ClientTravel para mudar de mapa.
  • Recompensas: chamadas HTTP via VaRest para Node.js gravar moedas no SQL antes de replicar saldo em APlayerState.

Passo a Passo – Quickly

  1. Crie um UDataAsset com configurações (tempo máximo, mapa, posição, reward coins).
  2. No AGameMode, implemente um RPC Server_StartQuickly(Map,Pos,Time) restrito a GMs.
  3. Instancie um AQuicklyNPC no mundo; replique seu Actor e vincule OnClicked a um RPC Server_ClickQuickly.
  4. Adicione um FTimerHandle no AGameState para decrementar RemainingTime; envie Multicast para HUD a cada minuto e nos últimos 5 segundos.
  5. No clique, valide sessão, chame VaRest para creditar moedas em Node.js/SQL e dispare partículas (Niagara) replicadas.

Passo a Passo – Run and Catch

  1. Crie um componente URunAndCatchComponent no AGameState contendo arrays de inscritos e tempo restante.
  2. Implemente Server_OpenRunAndCatch(Map,Pos,Duration) (somente GM) que liga o timer e permite inscrições.
  3. No APlayerController, um RPC Server_JoinRunAndCatch adiciona o jogador, seta bIsRunner replicado e teleporta para a posição do evento.
  4. Crie um Server_RegisterHit(Target) chamado quando o GM atinge um runner (line trace ou overlap); se restar um, chame VaRest para recompensa e marque WinnerId; caso contrário, teleporte o capturado para um gate (TeleportOutLocation).
  5. HUD: Widgets mostram contagem regressiva e nomes restantes; sincronize via rep-notify.

Checklist Final

  • Eventos Quickly e Run and Catch aparecem no HUD com contagem regressiva replicada.
  • GMs conseguem criar NPC Quickly e definir tempo/localização.
  • Recompensas de moedas são persistidas via VaRest/Node.js/SQL e refletidas no estado do jogador.
  • Run and Catch teleporta inscritos, controla entradas, elimina capturados e declara vencedor corretamente.

Guia "clique a clique" para iniciantes (Blueprints + VaRest/SQL)

Use este roteiro literal para recriar os dois eventos sem precisar escrever C++.

1) Dados, SQL e endpoints
  1. No Content Browser crie Struct ST_EventInstant com campos: NomeEvento (String), Mapa (Byte), PosX (Int), PosY (Int), TempoSeg (Int), RewardId (Int), RewardQty (Int), Avisos (Int).
  2. Crie DataTable DT_EventInstant usando a struct. Preencha:
    • Quickly_Default: Mapa=2, PosX=134, PosY=128, TempoSeg=300, RewardId=14, RewardQty=5, Avisos=5.
    • RunCatch_Default: Mapa=51, PosX=55, PosY=90, TempoSeg=180, RewardId=16, RewardQty=3, Avisos=3.
  3. Banco SQL: tabela InstantEventsLog(Id, EventName, Winner, Duration, RewardId, Qty, CreatedAt) e Winners(Name, Event) se quiser histórico separado.
  4. Backend Node.js (ou PHP) com rotas:
    POST /events/instant {eventName, winner, duration, rewardId, qty};
    POST /rewards/grant {account, itemId, amount};
    POST /notices/global {text}.
  5. No Blueprint BP_SQLBridge, crie funções SendEventLog (chama /events/instant) e GrantReward (chama /rewards/grant).
2) Painel do GM (Widget WBP_InstantPanel)
  1. Canvas ancorado no topo direito (Position X=1580, Y=32, Size X=300, Y=360).
  2. Adicione dois botões (Width=260, Height=44): BTN_Quickly e BTN_RunCatch. Texto: “Iniciar Quickly”, “Iniciar Run&Catch”.
  3. Abaixo, um EditableTextBox Tempo (DefaultText “300”) e outro de Recompensa (Default “Bless x5”).
  4. Bindings visuais: Checkbox “NPC Spawnado?” ligado a bool bNPCAtivo; Texto “Avisos restantes” ligado a int AvisosRestantes.
  5. OnClicked Quickly (clique a clique):
    • Node GetDataTableRow (RowName Quickly_Default) → Split Struct.
    • SpawnActor BP_EventQuickly → Set TempoRestante, PosX, PosY, RewardId, RewardQty, AvisosRestantes.
    • Chamar Multicast “ShowNotice” com texto “Quickly iniciado! Vá para (134,128)”.
    • Usar VaRest POST /events/instant (eventName="Quickly", winner="", duration=TempoSeg).
    • Marcar bNPCAtivo=true.
  6. Repita fluxo para Run&Catch usando RowName RunCatch_Default.
3) Actor Quickly (BP_EventQuickly)
  1. Componentes: Billboard, Sphere Collision Radius=120, TextRender “Quickly”.
  2. Variáveis replicadas: TempoRestante (int), AvisosRestantes (int), RewardId (int), RewardQty (int), WinnerName (string).
  3. No BeginPlay: SetTimer (loop 1s) chamando TickEvento.
  4. TickEvento:
    • TempoRestante--; se TempoRestante % 60 == 0 ou TempoRestante <= AvisosRestantes, chame Multicast ShowNotice + UI e toque som “Bell”.
    • Se TempoRestante <= 0 → chamar função Finalizar(false).
  5. OnComponentBeginOverlap (Sphere): se WinnerName vazio, setar para OtherActor.PlayerName e chamar Finalizar(true).
4) HUD do Jogador (WBP_EventHUD)
  1. Ancorar barra no topo centro (Position X=640, Y=32, Size X=640, Y=92).
  2. Elementos: Barra de progresso (Width=600, Height=12), Texto “Evento: Quickly”, Texto menor “Corra para (134,128)”, Ícone de sino 32x32.
  3. Binding: Percent = TempoRestante / TempoTotal; Texto de aviso vindo de ShowNotice multicast.
  4. Adicionar animação “FlashWarning” (Loop) e disparar quando TempoRestante <= 5.
5) Finalização + VaRest
  1. Função Finalizar(TemVencedor bool) em BP_EventQuickly:
    • Se TemVencedor: aviso “{WinnerName} venceu Quickly!”. Chame BP_SQLBridge.GrantReward(WinnerName, RewardId, RewardQty); play fogos.
    • Se não: aviso “Evento encerrado sem vencedor”.
    • Registrar BP_SQLBridge.SendEventLog com duração.
    • DestroyActor e limpar timer.
  2. Resete bNPCAtivo=false no painel do GM via RunOnOwningClient.
6) Run and Catch (Blueprint rápido)
  1. Crie BP_RunCatchManager (Actor replicado) com arrays Inscritos (PlayerState refs) e Ativos, int TempoRestante, bool bAberto.
  2. Função AbrirEvento: setar bAberto=true, TempoRestante=180, SetTimer 1s. Multicast aviso “Inscrições abertas em (55,90)”.
  3. Função Inscrever: RPC no PlayerController que adiciona à lista e teleporta para (55,90, Z=120). Tocou efeito “Spawn_Warp”.
  4. Tick: decrementa TempoRestante; se chega a 0 → finaliza sem vencedor; se Ativos.Num()==1 → vencedor recebe GrantReward.
  5. Registrar Hit: no GM, use LineTrace quando clicar; se acertar jogador ativo, remova-o e teleporte para gate de saída (mapa 0, coords 125,125). Atualize HUD via multicast.
7) Testes rápidos
  1. Iniciar Quickly, verificar spawn e aviso.
  2. Entrar na esfera, validar recompensa no SQL e no HUD.
  3. Rodar Run&Catch, inscrever 3 jogadores, eliminar 2 pelo GM, checar vencedor e log gravado.
  4. Desconectar rede durante evento e voltar: confirmar que HUD recupera tempo restante via variável replicada.
