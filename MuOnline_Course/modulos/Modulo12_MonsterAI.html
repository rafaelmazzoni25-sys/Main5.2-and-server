Módulo 12 – IA de Monstros e MovePath

Detalhamos o carregamento de elementos de IA e caminhos de movimento usados pelo GameServer para posicionar e dirigir monstros.

Pré-requisitos

  • Concluir os módulos 1, 6 e 8 para compreender bootstrap de servidor, timers e roteamento de pacotes.
  • Conhecer leitura de arquivos de configuração com CMemScript (visto em módulos anteriores).
  • Noções de AI Components em UE5 e navegação (NavMeshBoundsVolume e UNavigationSystemV1).

Conceitos do Código Original

Carregamento de elementos de IA – CMonsterAIElement::LoadData
📘 O Que é?

Rotina que lê definições de elementos de IA (classe, tipo, taxa de sucesso, delay, alvo e coordenadas) e popular arrays estáticos.

🎯 Para Que Serve?

Inicializa o catálogo de ações de IA por mapa, garantindo que cada elemento tenha parâmetros e posições válidas antes do loop do GameServer.

💻 Como Funciona?

void CMonsterAIElement::LoadData(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript == 0) { ErrorMessageBox(MEM_SCRIPT_ALLOC_ERROR,path); return; }
    if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); delete lpMemScript; return; }
    CMonsterAIElement::DelAllAIElement();
    try {
        while(true) {
            if(lpMemScript->GetToken() == TOKEN_END) { break; }
            int section = lpMemScript->GetNumber();
            while(true) {
                if(section == 0) {
                    if(strcmp("end",lpMemScript->GetAsString()) == 0) { break; }
                    CMonsterAIElementInfo info;
                    info.m_ElementNumber = lpMemScript->GetNumber();
                    strcpy_s(info.m_ElementName,lpMemScript->GetAsString());
                    info.m_ElementClass = lpMemScript->GetAsNumber();
                    info.m_ElementType = lpMemScript->GetAsNumber();
                    info.m_SuccessRate = lpMemScript->GetAsNumber();
                    info.m_DelayTime = lpMemScript->GetAsNumber();
                    info.m_TargetType = lpMemScript->GetAsNumber();
                    info.m_X = lpMemScript->GetAsNumber();
                    info.m_Y = lpMemScript->GetAsNumber();
                    if(info.m_ElementNumber >= 0 && info.m_ElementNumber < MAX_MONSTER_AI_ELEMENT_INFO) {
                        CMonsterAIElement::m_MonsterAIElementInfoArray[info.m_ElementNumber] = info;
                    }
                } else { break; }
            }
        }
    } catch(...) { ErrorMessageBox(lpMemScript->GetLastError()); }
    CMonsterAIElement::m_DataLoad = 1;
    CMonsterAIElement::m_MonsterAIMovePath[MAP_CRYWOLF].LoadData(gPath.GetFullPath("Monster\\MovePath\\MovePath_35.dat"));
    delete lpMemScript;
}

Reset e consulta de elementos – DelAllAIElement e FindAIElementInfo
📘 O Que é?

Métodos utilitários para limpar o catálogo de IA e localizar um elemento por índice.

🎯 Para Que Serve?

Evita lixo de memória entre recargas de script e permite recuperar configurações para decisões de IA.

💻 Como Funciona?

void CMonsterAIElement::DelAllAIElement() {
    CMonsterAIElement::m_DataLoad = 0;
    for(int n=0;n < MAX_MONSTER_AI_ELEMENT_INFO;n++) {
        CMonsterAIElement::m_MonsterAIElementInfoArray[n].Reset();
    }
}

CMonsterAIElementInfo* CMonsterAIElement::FindAIElementInfo(int ElementNumber) {
    if(ElementNumber < 0 || ElementNumber >= MAX_MONSTER_AI_ELEMENT_INFO) { return 0; }
    if(CMonsterAIElement::m_MonsterAIElementInfoArray[ElementNumber].m_ElementNumber == ElementNumber) {
        return &CMonsterAIElement::m_MonsterAIElementInfoArray[ElementNumber];
    }
    return 0;
}

MovePath de monstros – CMonsterAIMovePath::LoadData e GetMonsterNearestPath
📘 O Que é?

Carregamento e consulta de pontos de caminho para deslocamento de monstros.

🎯 Para Que Serve?

Define rotas pré-configuradas que guiam monstros entre posições, escolhendo o ponto mais próximo do alvo.

💻 Como Funciona?

void CMonsterAIMovePath::LoadData(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript == 0) { ErrorMessageBox(MEM_SCRIPT_ALLOC_ERROR,path); return; }
    if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); delete lpMemScript; return; }
    this->DelAllAIMonsterMovePath();
    try {
        while(true) {
            if(lpMemScript->GetToken() == TOKEN_END) { break; }
            int section = lpMemScript->GetNumber();
            while(true) {
                if(section == 2) {
                    if(strcmp("end",lpMemScript->GetAsString()) == 0) { break; }
                    CMonsterAIMovePathInfo info;
                    info.m_Type = lpMemScript->GetNumber();
                    info.m_MapNumber = lpMemScript->GetAsNumber();
                    info.m_PathX = lpMemScript->GetAsNumber();
                    info.m_PathY = lpMemScript->GetAsNumber();
                    if(this->m_MonsterAIMovePathInfoCount >= 0 && this->m_MonsterAIMovePathInfoCount < MAX_MONSTER_AI_MOVE_PATH_INFO) {
                        this->m_MonsterAIMovePathInfoArray[this->m_MonsterAIMovePathInfoCount++] = info;
                    }
                } else { break; }
            }
        }
    } catch(...) { ErrorMessageBox(lpMemScript->GetLastError()); }
    this->m_DataLoad = 1;
    delete lpMemScript;
}

void CMonsterAIMovePath::GetMonsterNearestPath(int sx,int sy,int tx,int ty,int* ox,int* oy,int NearestDistance) {
    for(int n=0;n < this->m_MonsterAIMovePathInfoCount;n++) {
        if(sqrt(pow(((float)sx-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathX),2)+pow(((float)sy-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathY),2)) < 10) {
            if(sqrt(pow(((float)tx-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathX),2)+pow(((float)ty-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathY),2)) < NearestDistance) {
                NearestDistance = (int)sqrt(pow(((float)tx-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathX),2)+pow(((float)ty-(float)this->m_MonsterAIMovePathInfoArray[n].m_PathY),2));
                (*ox) = this->m_MonsterAIMovePathInfoArray[n].m_PathX;
                (*oy) = this->m_MonsterAIMovePathInfoArray[n].m_PathY;
            }
        }
    }
}

Implementação em Unreal Engine 5

Mapearemos os elementos de IA para UDataAsset e caminhos para UNavigationPath/FNavLocation, com controladores herdando de AAIController.

Passo a Passo

  1. Crie uma Data Asset UAIElementDefinition com propriedades equivalentes (Classe, Tipo, Sucesso, Delay, TargetType, Posição) e uma lista em UAIElementTable.
  2. Implemente um importador (editor utility) que leia arquivos CSV/JSON extraídos dos scripts do servidor e preencha as assets.
  3. Crie um AAIController específico (ex.: ACrywolfMonsterAIController) que recebe uma referência para o UAIElementTable e mantém um índice para o elemento ativo.
  4. Para caminhos, crie um UDataAsset UMonsterMovePath com array de FVector e um método FindNearestPoint replicando o cálculo de distância.
  5. Na inicialização do nível, carregue as assets via ConstructorHelpers::FObjectFinder ou LoadObject, e injete no GameMode/Subsystem.
  6. Implemente no controlador: ao receber alvo (tx/ty), chame FindNearestPoint e ordene um MoveToLocation usando UNavigationSystemV1::SimpleMoveToLocation.
  7. Adicione um UBlackboardComponent e UBehaviorTree opcionais, com nós customizados para alternar entre estados NORMAL/MOVE/ATTACK conforme os elementos carregados.
  8. Para debug, exponha comandos de console que recarregam os DataAssets (equivalente a DelAllAIElement + LoadData) e desenhem linhas dos caminhos no viewport (DrawDebugLine).

Blueprints passo a passo (iniciante)

  1. No Content Drawer crie Blueprints/Monsters. Adicione Blueprint Class → Character chamada BP_Monster e marque Replicates (Net Update Frequency = 4) e Use Controller Rotation Yaw = false.
  2. No componente CharacterMovement, defina Max Walk Speed = 320, Rotation Rate Yaw = 720. Adicione um Sphere Collision AggroSphere raio 1200 e habilite Overlap com Pawn.
  3. Crie a Data Table DT_Monsters com colunas: Id, HP, Defense, MovePathId, SpawnX, SpawnY, Dir. Importe o CSV do servidor e garanta que SpawnX/SpawnY reflitam as coordenadas originais (1 unidade = 100 Unreal Units).
  4. No BP_Monster adicione variáveis: MovePath (Array Vector), PathIndex (Integer), IsInCombat (Bool), TargetActor (Actor). Marque MovePath como RepNotify e implemente OnRep_MovePath para reiniciar a patrulha.
  5. Crie uma função LoadPath: VaRest GET /path/{MapId}/{MovePathId}, faça ForEach em cada linha e converta em vetor (X*100, Y*100, 0). Se a requisição falhar, leia arquivo local Content/Monsters/MovePath_{MapId}.csv.
  6. Adicione um Custom Event AdvancePath. Se MovePath estiver vazio, retorne. Caso o PathIndex exceda, zere. Pegue NextPoint = MovePath[PathIndex] e use AI Move To (Acceptance Radius 75). No On Success incremente PathIndex e chame AdvancePath após Delay 0.2.
  7. Configurar combate: no AggroSphere.OnBeginOverlap, se outro for BP_Player, grave em TargetActor, pare a patrulha (Clear Timer do AdvancePath) e chame AI Move To com Acceptance Radius 140. Ao chegar, dispare ServerTryAttack (Run on Server) chamando VaRest POST /monster/attack e aplique dano.
  8. UI de debug: crie WBP_MonsterInspector (âncora topo esquerdo, X=24, Y=24) com ListView. A cada Tick, preencha com Name, HP, PathIndex e coordenadas. Use cores: verde (patrulhando), laranja (recalculando), vermelho (combate).
  9. Persistência SQL: a cada 20s execute VaRest POST /monster/state com Id, HP, PathIndex, Location. Se o servidor reiniciar, chame VaRest GET /monster/state ao spawn e aplique SetActorLocation + PathIndex para retomar o caminho.
  10. Teste controlado: em PIE Multiplayer 2, arraste dois jogadores na frente do monstro. Observe se ele troca de patrulha para combate e volta ao patrulhamento após 3s sem alvo. Valide se o WBP_MonsterInspector mostra o PathIndex correto.

UCLASS()
class UMoverPathData : public UDataAsset {
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere) TArray Points;
    UFUNCTION(BlueprintCallable)
    FVector FindNearestPoint(const FVector& Start,const FVector& Target,float Threshold=1000.f) const;
};

FVector UMoverPathData::FindNearestPoint(const FVector& Start,const FVector& Target,float Threshold) const {
    float Best = Threshold;
    FVector Result = Target;
    for(const FVector& P : Points) {
        if(FVector::Dist2D(Start,P) < 1000.f && FVector::Dist2D(Target,P) < Best) {
            Best = FVector::Dist2D(Target,P);
            Result = P;
        }
    }
    return Result;
}

UCLASS()
