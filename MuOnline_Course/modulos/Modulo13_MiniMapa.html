Conceitos do Código Original

Carregamento de marcadores – CMiniMap::Load
📘 O Que é?

Função que lê um script de minimapa e monta a lista de MINI_MAP_INFO para cada mapa.

🎯 Para Que Serve?

Disponibiliza textos e coordenadas que serão enviados ao cliente quando ele habilitar o minimapa.

💻 Como Funciona?

void CMiniMap::Load(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript == 0) { ErrorMessageBox(MEM_SCRIPT_ALLOC_ERROR,path); return; }
    if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); delete lpMemScript; return; }
    this->m_MiniMapInfo.clear();
    try {
        while(true) {
            if(lpMemScript->GetToken() == TOKEN_END) { break; }
            if(strcmp("end",lpMemScript->GetString()) == 0) { break; }
            MINI_MAP_INFO info; memset(&info,0,sizeof(info));
            info.Index = lpMemScript->GetNumber();
            info.Group = lpMemScript->GetAsNumber();
            info.Type = lpMemScript->GetAsNumber();
            info.X = lpMemScript->GetAsNumber();
            info.Y = lpMemScript->GetAsNumber();
            strcpy_s(info.Text,lpMemScript->GetAsString());
            this->m_MiniMapInfo.push_back(info);
        }
    } catch(...) { ErrorMessageBox(lpMemScript->GetLastError()); }
    delete lpMemScript;
}

Envio das posições da party – GCMiniMapPartyInfoSend
📘 O Que é?

Handler que percorre os membros da party e envia um pacote 0xE7 0x01 com mapa e coordenadas.

🎯 Para Que Serve?

Sincroniza em tempo real a localização de aliados para exibição no minimapa do cliente.

💻 Como Funciona?

void CMiniMap::GCMiniMapPartyInfoSend(int aIndex) {
    if(gObj[aIndex].MiniMapState == 0) { return; }
    int index = gObj[aIndex].PartyNumber;
    if(index == -1) { return; }
    BYTE send[256];
    PMSG_MINI_MAP_PARTY_INFO_SEND pMsg; pMsg.header.set(0xE7,0x01,0);
    int size = sizeof(pMsg); pMsg.count = 0; PMSG_MINI_MAP_PARTY_INFO info;
    for(int n=0;n < MAX_PARTY_USER;n++) {
        if(OBJECT_RANGE(gParty.m_PartyInfo[index].Index[n]) == 0) { continue; }
        LPOBJ lpObj = &gObj[gParty.m_PartyInfo[index].Index[n]];
        memcpy(info.name,lpObj->Name,sizeof(info.name));
        info.map = lpObj->Map; info.x = (BYTE)lpObj->X; info.y = (BYTE)lpObj->Y;
        memcpy(&send[size],&info,sizeof(info)); size += sizeof(info); pMsg.count++;
    }
    pMsg.header.size = size; memcpy(send,&pMsg,sizeof(pMsg));
    DataSend(aIndex,send,size);
}

Envio de marcadores do mapa – GCMiniMapInfoSend
📘 O Que é?

Itera o vetor de marcadores do mapa atual e envia cada entrada ao cliente.

🎯 Para Que Serve?

Entrega labels e coordenadas estáticas (NPCs, portais) para renderização local.

💻 Como Funciona?

void CMiniMap::GCMiniMapInfoSend(int aIndex) {
    int count = 0;
    for(std::vector::iterator it=this->m_MiniMapInfo.begin();it != this->m_MiniMapInfo.end();it++) {
        if(it->Index != gObj[aIndex].Map) { continue; }
        PMSG_MINI_MAP_INFO_SEND pMsg; pMsg.header.set(0xE7,0x03,sizeof(pMsg));
        pMsg.index = count++; pMsg.group = it->Group; pMsg.type = it->Type; pMsg.flag = 0;
        pMsg.x = it->X; pMsg.y = it->Y; memcpy(pMsg.text,it->Text,sizeof(pMsg.text));
        DataSend(aIndex,(BYTE*)&pMsg,pMsg.header.size);
    }
}

Implementação em Unreal Engine 5

Usaremos UMG para a UI, replicação de structs para coordenadas e um DataTable para marcadores.

Passo a Passo

  1. Crie um UDataTable (struct FMinimapMarkerRow com mapa, grupo, tipo, posição, texto) e popule a partir do script original exportado.
  2. No GameState, mantenha um TArray<FPartyMinimapEntry> replicado contendo nome, mapa, X, Y de cada membro.
  3. Implemente um UUserWidget que desenha marcadores fixos lendo o DataTable filtrado pelo mapa atual.
  4. Adicione um componente UPartyLocationComponent no PlayerState para publicar periodicamente a posição (via RPC server -> multicast) aos membros.
  5. No cliente, subscreva eventos de atualização para redesenhar pinos da party; inclua timers de refresh baseados no tick para simular o envio de GCMiniMapPartyInfoSend.
  6. Mapeie hotkey para abrir/fechar o minimapa, definindo um booleano replicado similar a MiniMapState.
  7. Inclua integração opcional com VaRest para persistir waypoints no backend (Node.js + SQL) e recarregar no login.

Checklist Final

  • Minimapa exibe marcadores fixos por mapa a partir do DataTable.
  • Coordenadas da party aparecem e atualizam em tempo real no widget.
  • Toggle de minimapa respeita o estado replicado e recarrega marcadores ao mudar de mapa.
