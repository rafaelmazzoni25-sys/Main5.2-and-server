Módulo 54 – Enums de Buffs, Debuffs e Estados

Cataloga e adapta os enums de buffs/debuffs, classes e flags de estado presentes no código legado C++ (carregados via BuffEffect_*.bmd) para DataTables, Blueprints e UI na Unreal Engine 5.

Enums e Estruturas do Código Legado

Índices de Buff (eBuffState)

Persistidos nos arquivos data/local/<ML>/BuffEffect_<ML>.bmd e lidos por w_BuffScriptLoader. Exemplos típicos:

  • Buffs ofensivos: eBuff_WizardSpeed, eBuff_ClawPoison, eBuff_SwellLife, eBuff_Strengthen.
  • Buffs defensivos: eBuff_Defense, eBuff_GreaterDefense, eBuff_ShieldSkillDefense, eBuff_Bless.
  • Debuffs/CC: eDeBuff_Poison, eDeBuff_Freeze, eDeBuff_Stun, eDeBuff_Bleeding, eDeBuff_CursedTempleRestraint.
  • Estados especiais: eBuff_Cloaking, eBuff_TransformationRing, eBuff_RageFighterDarkSide, eBuff_CastleGateDefense.

Localização: parser em Source Main 5.2/source/w_BuffScriptLoader.cpp / .h, com uso de BUFFINDEX e MAX_BUFF_SLOT_INDEX definidos em _define.h. As descrições e classes são carregadas nos campos s_BuffClassType, s_BuffEffectType e s_ClearType.

Classes de Buff (eBuffClass)

Definem o agrupamento para UI e regras de pilha:

  • eBuffClass_Common – buffs padrão (Bless, Soul, Great Defense/Attack).
  • eBuffClass_Skill – buffs vindos de skills ativas (WizardSpeed, Increase Critical, Rage Fighter buffs).
  • eBuffClass_Item – buffs oriundos de itens/eventos (Scrolls, Fruits, Pets).
  • eBuffClass_Event – buffs de eventos (Crywolf, Cursed Temple Protection/Restraint, Siege Guardian).
  • eBuffClass_Debuff – debuffs que ocupam slots separados (Poison, Freeze, Stun, Bleeding, Curse).

Localização: campo s_BuffClassType de _BUFFINFO carregado em w_BuffScriptLoader; a janela NewUIBuffWindow ordena e renderiza via BuffSort.

Clear/Notice e Efeito

O C++ define metadados adicionais:

  • s_ClearType: indica se o buff é removido por morte, por tempo ou por comando (ex.: cancelamento de Cursed Temple).
  • s_NoticeType: define se há anúncio na ativação (level-up buffs mostram tooltip e som).
  • s_BuffEffectType: linka para assets FX/sons específicos (ex.: Speed usa som de passos e trilha azul).

Localização: campos de _BUFFINFO em w_BuffScriptLoader.h; usados por NewUIBuffWindow para tooltip e som.

Replicação 1:1 na Unreal Engine 5

  1. DataTable de Buffs: Crie DT_Buffs com colunas BuffId (int), Name (Text), Description (Text), Class (enum), EffectType (int), ClearType (enum), Icon (Texture2D), DurationSec (float). Preencha com todos os índices do BuffEffect_*.bmd lido no C++.
  2. Enum Blueprint E_BuffState: Replique os nomes legados (ex.: Buff_WizardSpeed, DeBuff_Poison, Buff_GreaterDefense, Buff_CursedTempleProtection) para uso em nós Switch on E_BuffState.
  3. Componente BP_BuffComponent: No Tick do servidor, decréscimo do tempo restante por buff. Ao adicionar/remover, dispare Multicast_UpdateBuffs com array replicado de structs {BuffId, EndTime, Stacks}. Conecte OnRep no cliente à UI.
  4. UI WBP_BuffBar: Lista horizontal para buffs comuns e vertical para debuffs (igual a NewUIBuffWindow). Use For Each nos arrays replicados → Get Data Table Row → cria widget item com ícone, contador e tooltip com Description e NoticeType.
  5. FX e som por EffectType: Monte DT_BuffEffects (BuffId → NiagaraSystem/SoundCue). Ao ativar, acione Spawn System Attached no mesh do personagem e Play Sound 2D usando o roteamento do módulo 52. Para debuffs como Bleeding, use Spawn Decal Attached na origem.
  6. ClearType/Desconexão: No BP_ServerPersistence (módulo 49/10), serialize apenas buffs cujo ClearType seja Persist; remova buffs OnDeath ao receber evento de morte (módulo 4) chamando Remove Buff com ClearType == OnDeath.
  7. Compatibilidade com efeitos de transformação: Para eBuff_TransformationRing e similares, associe em DT_Buffs um SkeletalMesh alternativo e, no componente, troque o mesh/AnimBP durante a duração do buff, revertendo ao expirar.

Checklist Final

  • Todos os índices de BuffEffect_*.bmd copiados para DT_Buffs com classe, efeito e clear type preenchidos.
  • E_BuffState contém a mesma lista de nomes do legado e é usado em todos os Switch de aplicação/remoção.
  • BP_BuffComponent replica tempo restante, dispara FX/sons por EffectType e limpa conforme ClearType.
  • WBP_BuffBar mostra buffs/debuffs com ícone, tempo e tooltip, alinhado ao layout original.
