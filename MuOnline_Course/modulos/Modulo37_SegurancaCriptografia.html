Módulo 37 – Segurança e Criptografia de Pacotes

Examina o HackCheck: geração de chaves com dados do servidor, criptografia/decodificação de pacotes e inicialização no GameMainInit. Inclui a reimplementação fiel em UE5 usando sockets e uma camada opcional HTTP via VaRest + Node.js para chaves dinâmicas.

Pré-requisitos

  • Módulo 1 – Arquitetura e Bootstrap (para entender o GameMainInit).
  • Módulo 2 – Rede e Autenticação.
  • Experiência com FSocket em UE5 e interceptação de buffers antes do envio.

Conceitos do Código Original

EncryptData / DecryptData – XOR com chaves variáveis
📘 O Que é?

Rotinas que embaralham bytes de cada pacote usando chaves globais EncDecKey1/2 e as variantes do MHP quando habilitadas.

void DecryptData(BYTE* lpMsg,int size) {
  if(MHPEncDecKey1 != 0 || MHPEncDecKey2 != 0) { MHPDecryptData(lpMsg,size); }
  for(int n=0;n < size;n++) { lpMsg[n] = (lpMsg[n]^EncDecKey1)-EncDecKey2; }
}
void EncryptData(BYTE* lpMsg,int size) {
  for(int n=0;n < size;n++) { lpMsg[n] = (lpMsg[n]+EncDecKey2)^EncDecKey1; }
  if(MHPEncDecKey1 != 0 || MHPEncDecKey2 != 0) { MHPEncryptData(lpMsg,size); }
}

🎯 Para Que Serve?

Protege o tráfego do GameServer contra interceptação simples, aplicando uma cifra XOR simétrica em todos os pacotes e opcionalmente rodadas extras (MHP) quando configurado.

💻 Como Funciona?

Primeiro tenta decodificar com as chaves MHP (se definidas), depois aplica uma subtração/XOR byte a byte usando EncDecKey1/2. O caminho inverso soma/XOR e volta a cifrar com MHP.

if(MHPEncDecKey1 != 0 || MHPEncDecKey2 != 0) { MHPDecryptData(lpMsg,size); }
for(int n=0;n < size;n++) { lpMsg[n] = (lpMsg[n]^EncDecKey1)-EncDecKey2; }

InitHackCheck – Derivação de chaves e leitura de MHP
📘 O Que é?

Função de inicialização que calcula EncDecKey1/2 a partir do nome do cliente (m_CustomerName) e do serial do servidor, além de carregar chaves extras do arquivo MHPServer.ini.

🎯 Para Que Serve?

Garante que cada build tenha chaves diferentes (dependentes do serial), evitando que a cifra simples seja igual entre shards. Também habilita a camada MHP se o INI fornecer chaves.

💻 Como Funciona?

Soma os bytes de CustomerName ^ ServerSerial, soma aos valores base (0xE2/0x76 ou 0xEE/0xFF), e carrega EncDecKey1/2. Caso MHP esteja configurado, ajusta MHPEncDecKey1/2 com a soma do nome do cliente.

WORD EncDecKey = 0;
for(int n=0;n < sizeof(gServerInfo.m_CustomerName);n++) {
  EncDecKey += (BYTE)(gServerInfo.m_CustomerName[n]^gServerInfo.m_ServerSerial[n%sizeof(gServerInfo.m_ServerSerial)]);
}
EncDecKey1 = 0xE2 + LOBYTE(EncDecKey);
EncDecKey2 = 0x76 + HIBYTE(EncDecKey);
MHPEncDecKey1 = GetPrivateProfileInt("MHPServerInfo","EncDecKey1",0,"..\\Data\\Hack\\MHPServer.ini");

Implementação em Unreal Engine 5

Meta: replicar a cifra XOR e a derivação de chaves antes de qualquer envio/recebimento de socket (ou camada HTTP com VaRest).

  1. Crie um USubsystem ou UActorComponent UHackCheckComponent anexado ao UGameInstance para inicializar chaves no Init().
  2. No Init(), leia um DataTable/arquivo INI com CustomerName, ServerSerial e chaves MHP (se usadas) para derivar EncDecKey1/2 espelhando a soma do código original.
  3. Intercepte envios em FSocket::Send criando um wrapper que aplica EncryptData antes de enviar e outro wrapper para Recv com DecryptData.
  4. Para HTTP (VaRest + Node.js + SQL): disponibilize um endpoint /hack/keys que retorna as chaves calculadas no servidor Node.js; no cliente UE5, faça UVaRestRequestJSON no boot e popular o componente com as chaves retornadas.
  5. Implemente testes automatizados criando pacotes fictícios, cifrando e decifrando e validando igualdade do buffer.
Exemplo UE5 – Componente de Criptografia
UCLASS()
class UHackCheckComponent : public UActorComponent {
  GENERATED_BODY()
public:
  UPROPERTY() uint8 EncDecKey1, EncDecKey2, MHP1, MHP2;
  virtual void InitializeComponent() override { Super::InitializeComponent(); DeriveKeys(); }
  void DeriveKeys();
  void Encrypt(TArray& Buffer);
  void Decrypt(TArray& Buffer);
};

void UHackCheckComponent::Encrypt(TArray& Buffer) {
  for (uint8& B : Buffer) { B = (B + EncDecKey2) ^ EncDecKey1; }
  if (MHP1 || MHP2) { for (uint8& B : Buffer) { B = (B + MHP2) ^ MHP1; } }
}

Diferenças: usar TArray<uint8> gerenciado e injetar o componente no pipeline de rede (UClientNetDriver customizado) em vez de funções globais.

Passo a Passo em Unreal Engine 5

  1. No GameInstance, instancie UHackCheckComponent e chame DeriveKeys no Init().
  2. Substitua o UNetDriver ou crie um wrapper de FSocket para aplicar Encrypt/Decrypt em todos os buffers.
  3. Implemente um endpoint Node.js /hack/keys que lê CustomerName/ServerSerial do SQL e devolve chaves; no cliente, use VaRest na inicialização offline para sincronizar valores.
  4. Crie testes unitários em UE5 (AutomationTest) comparando buffer original ↔ cifrado ↔ decifrado.
  5. Valide em runtime com um servidor de eco TCP Node.js para garantir compatibilidade binária.

Checklist Final

  • Chaves derivadas no boot replicam o cálculo do GameServer.
  • Toda mensagem enviada pelo cliente UE5 passa por Encrypt; toda recebida passa por Decrypt.
  • Endpoint Node.js/SQL opcional entregue e consumido via VaRest.
  • Testes de ida/volta confirmam buffers idênticos após decodificação.
