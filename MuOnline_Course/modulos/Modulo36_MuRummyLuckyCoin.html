CMuRummyMng::SetCardDeck/CardShuffle – Montagem e embaralhamento do baralho
📘 O Que é?

Inicializa 5 cores × 5 números (25 cartas), limpa slots e embaralha o deck para uso na sessão do jogador.

void CMuRummyMng::SetCardDeck(CMuRummyInfo* pMuRummyInfo) {
  int nCardArr = 0; CMuRummyCardInfo* pCCardInfo = pMuRummyInfo->GetCardInfo();
  for (int nCardColor = 0; nCardColor < MURUMMY_MAX_CARD_COLOR; nCardColor++) {
    for (int nCardNum = 0; nCardNum < MURUMMY_MAX_SLOT; nCardNum++) {
      pCCardInfo[nCardArr].SetColor(nCardColor + 1); pCCardInfo[nCardArr].SetNumber(nCardNum + 1);
      pCCardInfo[nCardArr].SetState(0); pCCardInfo[nCardArr].SetSlotNum(0); nCardArr++;
    }
  }
  LPBYTE pSlotIndexInfo = pMuRummyInfo->GetSlotIndexInfo(); for (int i = 0; i < MURUMMY_MAX_SLOT; i++) { pSlotIndexInfo[i] = -1; }
  pMuRummyInfo->SetCardDeckCnt(MURUMMY_MAX_CARD);
}
void CMuRummyMng::CardShuffle(CMuRummyCardInfo* pCCardInfo) {
  CMuRummyCardInfo CardInfoTmp;
  for (int nCnt = 0; nCnt < MURUMMY_MAX_CARD; nCnt++) {
    DWORD iIndex = nCnt + GetLargeRand() % (MURUMMY_MAX_CARD - nCnt);
    CardInfoTmp = pCCardInfo[nCnt];
    pCCardInfo[nCnt] = pCCardInfo[iIndex];
    pCCardInfo[iIndex] = CardInfoTmp;
  }
}

🎯 Para Que Serve?

Configura o baralho inicial da sessão MuRummy para cada jogador e gera uma ordem aleatória de compra.

💻 Como Funciona?

Preenche o vetor de cartas com cor/número e reseta estados. Em seguida, embaralha usando swaps aleatórios com GetLargeRand().

CMuRummyMng::SetPlayCardInfo – Construção do estado enviado ao cliente
📘 O Que é?

Copiando cartas marcadas como estado 1 para um array de saída que será enviado ao cliente.

🎯 Para Que Serve?

Controla quais cartas estão ativas no tabuleiro e limita a 5 cartas, preenchendo cor/número/slot.

💻 Como Funciona?

bool CMuRummyMng::SetPlayCardInfo(CMuRummyInfo* pMuRummyInfo, _tagMuRummyCardInfo* pOutCardInfo) {
  int nCardCnt = 0; CMuRummyCardInfo* pCCardInfo = pMuRummyInfo->GetCardInfo(); LPBYTE pSlotIndexInfo = pMuRummyInfo->GetSlotIndexInfo();
  for (int nCnt = 0; nCnt < MURUMMY_MAX_SLOT; nCnt++) {
    int nCardArr = pSlotIndexInfo[nCnt]; if (nCardArr < 0 || nCardArr >= MURUMMY_MAX_CARD) continue;
    if (pCCardInfo[nCardArr].GetState() == 1) {
      pOutCardInfo[nCardCnt].btColor = pCCardInfo[nCardArr].GetColor();
      pOutCardInfo[nCardCnt].btNumber = pCCardInfo[nCardArr].GetNumber();
      pOutCardInfo[nCardCnt].btSlotNum = pCCardInfo[nCardArr].GetSlotNum();
      nCardCnt++;
    }
  }
  return true;
}

📘 O Que é?

Implementação em Unreal Engine 5

MuRummy pode ser um minigame local replicado via AGameState ou AActor gerenciado pelo servidor, enquanto Lucky Coin pode ser tratado com HTTP + replicação leve.

  1. Crie um UDataAsset com definições de cores/números e recompensas de MuRummy.
  2. Implemente um AMuRummyGameActor com arrays replicados de cartas e função ShuffleDeck equivalente a CardShuffle.
  3. Use UUserWidget para UI de slots; sincronize estados via NetMulticast para todos os clientes na sessão.
  4. Para Lucky Coin, crie um componente ULuckyCoinComponent com métodos ServerRequestCount, ServerRegisterCoin e ServerExchange; cada um chama VaRest para endpoints Node.js (/api/lucky/count, /api/lucky/register, /api/lucky/exchange) e atualiza variáveis replicadas.
  5. Persistir no SQL via Node.js, retornando JSON com saldo e recompensas; atualizar UI no cliente.
