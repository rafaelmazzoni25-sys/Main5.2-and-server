CPentagramSystem::Load – Carregamento de tipos e opções
📘 O Que é?

Função responsável por ler arquivos de configuração de tipos e opções de joias Pentagram, populando mapas internos.

void CPentagramSystem::Load(char* path) // OK {
  CMemScript* lpMemScript = new CMemScript;
  ...
  while(true) {
    if(lpMemScript->GetToken() == TOKEN_END) break;
    int section = lpMemScript->GetNumber();
    while(true) {
      if(section == 0) {
        if(strcmp("end",lpMemScript->GetAsString()) == 0) break;
        PENTAGRAM_TYPE_INFO info;
        info.Index = lpMemScript->GetNumber();
        info.OptionIndex1 = lpMemScript->GetAsNumber();
        info.OptionIndex1 = lpMemScript->GetAsNumber();
        this->m_PentagramTypeInfo.insert(std::pair<int,PENTAGRAM_TYPE_INFO>(info.Index,info));
      } else if(section == 1) {
        if(strcmp("end",lpMemScript->GetAsString()) == 0) break;
        PENTAGRAM_OPTION_INFO info;
        info.Index = lpMemScript->GetNumber();
        lpMemScript->GetToken();
        info.Value = lpMemScript->GetAsNumber();
        for(int n=0;n < MAX_PENTAGRAM_JEWEL_RANK;n++) {
          info.Type[n] = lpMemScript->GetAsNumber();
          info.Rank[n] = lpMemScript->GetAsNumber();
          info.Level[n] = lpMemScript->GetAsNumber();
        }
        this->m_PentagramOptionInfo.insert(std::pair<int,PENTAGRAM_OPTION_INFO>(info.Index,info));
      }
    }
  }
}

🎯 Para Que Serve?

Carrega tabelas de tipos de Pentagram e opções de joias elementais, permitindo que o servidor valide slots, ranks e níveis ao equipar e ao calcular bônus.

💻 Como Funciona?

  1. Instancia CMemScript para abrir o arquivo informado.
  2. Lê tokens sequenciais; a seção 0 popula m_PentagramTypeInfo com index e opções padrão.
  3. A seção 1 lê PENTAGRAM_OPTION_INFO, preenchendo valores por rank/level.
  4. Armazena tudo em mapas associativos para consultas futuras em cálculo de atributos.

CPentagramSystem::LoadJewel – Configuração de joias e rank
📘 O Que é?

Leitura dos dados de joias Pentagram e tabela de upgrade de rank/level.

void CPentagramSystem::LoadJewel(char* path) // OK {
  CMemScript* lpMemScript = new CMemScript;
  ...
  while(true) {
    if(lpMemScript->GetToken() == TOKEN_END) break;
    int section = lpMemScript->GetNumber();
    while(true) {
      if(section == 0) {
        if(strcmp("end",lpMemScript->GetAsString()) == 0) break;
        PENTAGRAM_JEWEL_OPTION_INFO info;
        info.Index = lpMemScript->GetNumber();
        info.ItemIndex = lpMemScript->GetAsNumber();
        info.RankNumber = lpMemScript->GetAsNumber();
        info.RankOption = lpMemScript->GetAsNumber();
        info.RankOptionRate = lpMemScript->GetAsNumber();
        lpMemScript->GetToken();
        for(int n=0;n < MAX_PENTAGRAM_JEWEL_LEVEL;n++) {
          info.RankOptionValue[n] = lpMemScript->GetAsNumber();
        }
        this->m_PentagramJewelOptionInfo.insert(std::pair<int,PENTAGRAM_JEWEL_OPTION_INFO>(info.Index,info));
      } else { break; }
    }
  }
}

🎯 Para Que Serve?

Define as opções por joia, rank e nível, permitindo cálculos corretos de bônus e custos de upgrade/removal.

💻 Como Funciona?

  1. Lê seções do script de joias.
  2. Para cada joia, coleta índices de item e atributos por rank/nível.
  3. Insere tudo em m_PentagramJewelOptionInfo para consultas de upgrade.

Implementação em Unreal Engine 5

Recriaremos o sistema como componentes e DataAssets, preservando tabelas de ranks, slots e upgrades.

  1. Crie um DataAsset UPentagramTypeData contendo um array de structs para Index e opções (BlueprintType).
  2. Crie um DataAsset UPentagramJewelData com arrays por rank/nível e valores.
  3. Implemente um componente UPentagramComponent derivado de UActorComponent anexado ao personagem para armazenar joias equipadas e consultar bônus.
  4. Adicione função LoadFromTable() no componente para ler os DataAssets (equivalente ao Load / LoadJewel).
  5. Implemente validações de slot ao equipar item em APlayerController ou UInventoryComponent, consultando UPentagramComponent.
  6. Para upgrades, crie uma BlueprintCallable UpgradeJewel(int32 ItemId, int32 DesiredRank) que consulta as tabelas e aplica custos (Gold/Itens) sincronizados com o servidor.
  7. Na camada servidor UE5, exponha um endpoint HTTP via Node.js/SQL (ou RPC) que persiste composição de slots no banco; no cliente, use VaRest para enviar POST /pentagram/save ao salvar.
  8. Implemente replicação: marque arrays de slots com UPROPERTY(Replicated) e sincronize em GetLifetimeReplicatedProps para multiplayer.
  9. Adicione UI (UMG) para mostrar slots e ranks, com bindings aos arrays replicados e botões que chamam UpgradeJewel.

Checklist Final

  • DataAssets de tipos e joias carregam corretamente e são acessíveis pelo componente.
  • Validação de slot/Rank/Level impede joias inválidas (sem crash).
  • Upgrade e remoção consultam tabelas e disparam persistência via Node.js/SQL (VaRest no cliente).
  • Estado dos slots replica para demais clientes em multiplayer.
