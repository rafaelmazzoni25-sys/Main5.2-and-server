CMossMerchant::Load – Script de horários e loot
📘 O Que é?

Carrega horários de spawn e tabela de itens com grupos e probabilidades.

void CMossMerchant::Load(char* path) {
  CMemScript* lpMemScript = new CMemScript;
  if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); return; }
  m_MossMerchantStartTime.clear(); m_MossMerchantItemInfo.clear();
  while(true) {
    if(lpMemScript->GetToken() == TOKEN_END) break;
    int section = lpMemScript->GetNumber();
    while(true) {
      if(section == 0) { MOSS_MERCHANT_START_TIME info; info.Year = lpMemScript->GetNumber(); info.Month = lpMemScript->GetAsNumber(); info.Day = lpMemScript->GetAsNumber(); info.DayOfWeek = lpMemScript->GetAsNumber(); info.Hour = lpMemScript->GetAsNumber(); info.Minute = lpMemScript->GetAsNumber(); info.Second = lpMemScript->GetAsNumber(); m_MossMerchantStartTime.push_back(info); }
      else if(section == 1) { MOSS_MERCHANT_ITEM_INFO info; info.Index = lpMemScript->GetNumber(); info.Group = lpMemScript->GetAsNumber(); info.Option0 = lpMemScript->GetAsNumber(); ... info.Option6 = lpMemScript->GetAsNumber(); info.GambleRate = lpMemScript->GetAsNumber(); m_MossMerchantItemInfo.push_back(info); }
      else { break; }
    }
  }
}

MainProc/SetState – Countdown e avisos 208/209
📘 O Que é?

Timer de 1s que controla o estado (BLANK/EMPTY/START), atualiza painel e dispara avisos globais.

void CMossMerchant::MainProc() {
  DWORD elapsed = GetTickCount()-m_TickCount; if(elapsed < 1000) return; m_TickCount = GetTickCount();
  m_RemainTime = (int)difftime(m_TargetTime,time(0));
  if(gServerInfo.m_MossMerchantEvent == 0) { if (gServerDisplayer.EventMoss != -1) gServerDisplayer.EventMoss = -1; }
  else { if (m_State == MOSS_STATE_EMPTY) gServerDisplayer.EventMoss = m_RemainTime; else if (gServerDisplayer.EventMoss != 0) gServerDisplayer.EventMoss = 0; }
  switch(m_State) { case MOSS_STATE_EMPTY: ProcState_EMPTY(); break; case MOSS_STATE_START: ProcState_START(); break; }
}
void CMossMerchant::ProcState_EMPTY() {
  if(m_RemainTime <= 0) { gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(208)); SetState(MOSS_STATE_START); }
}
void CMossMerchant::ProcState_START() {
  if(m_RemainTime <= 0) { gNotice.GCNoticeSendToAll(...,gMessage.GetMessage(209)); SetState(MOSS_STATE_EMPTY); }
}

🎯 Para Que Serve?

Envia avisos de abertura/fechamento e mantém o painel de eventos com o tempo restante.

💻 Como Funciona?

CheckSync calcula o próximo horário; SetState_EMPTY limpa o NPC existente; SetState_START instancia e define RemainTime conforme gServerInfo.m_MossMerchantEventTime.

SetMossMerchant e GambleItem – Spawn do NPC e roleta de opções
📘 O Que é?

Cria o NPC 492 em Elbeland, registra o índice e executa a roleta de itens ao interagir.

🎯 Para Que Serve?

Materializa o Moss Merchant e entrega itens com opções/sockets baseadas nas taxas configuradas.

💻 Como Funciona?

void CMossMerchant::SetMossMerchant() {
  if(OBJECT_RANGE(m_MossMerchantIndex)) return;
  int index = gObjAddMonster(MAP_ELBELAND); if(OBJECT_RANGE(index)==0) return;
  LPOBJ lpObj = &gObj[index]; int px=22, py=225; lpObj->X=px; lpObj->Y=py; lpObj->Map=51; if(gObjSetMonster(index,492)==0) { gObjDel(index); return; }
  m_MossMerchantIndex = index;
}
bool CMossMerchant::GambleItem(LPOBJ lpObj,int group) {
  if(m_State != MOSS_STATE_START) return 0; if(gItemManager.CheckItemInventorySpace(lpObj,2,4)==0) return 0;
  CRandomManager RandomManager; for(auto it:m_MossMerchantItemInfo) if(it.Group==group) RandomManager.AddElement((int)(&it),it.GambleRate);
  MOSS_MERCHANT_ITEM_INFO* lpMossMerchantItemInfo = 0; if(RandomManager.GetRandomElement((int*)&lpMossMerchantItemInfo)==0) return 0;
  WORD ItemIndex = lpMossMerchantItemInfo->Index; BYTE ItemLevel=0; BYTE ItemOption1=0; ... BYTE ItemSocketOption[MAX_SOCKET_OPTION]={0xFF,...};
  gItemOptionRate.GetItemOption0(lpMossMerchantItemInfo->Option0,&ItemLevel);
  gItemOptionRate.GetItemOption6(lpMossMerchantItemInfo->Option6,&ItemSocketOption[0]);
  gItemOptionRate.MakeSocketOption(ItemIndex,ItemSocketOption[0],&ItemSocketOption[0]);
  GDCreateItemSend(lpObj->Index,0xEB,0,0,ItemIndex,ItemLevel,0,ItemOption1,ItemOption2,ItemOption3,-1,ItemNewOption,ItemSetOption,0,0,ItemSocketOption,0xFF,0);
  return 1;
}

Implementação em Unreal Engine 5

Use um DataTable de loot e um AActor MossMerchant que roda no servidor com RPCs.

  1. Crie uma USTRUCT FMossLootRow com ItemId, Group, Rates e opções; associe a um DataTable.
  2. Implemente um AGameState ou UWorldSubsystem que replica o estado (Blank/Empty/Start) e um timer de 1s, semelhante ao MainProc.
  3. No estado START, faça SpawnActor<AMossMerchantNPC> em Elbeland ou outro nível; armazene referência replicada.
  4. Dentro do NPC, exponha um Server RPC ServerRollLoot(int32 Group) que valida distância e chama uma função de roleta usando os rates do DataTable.
  5. Monte as opções usando structs (Level, Option1, Option2, Option3, Sockets) e crie o item via UInventoryComponent::AddItem; para itens premium, poste no Node.js via VaRest (/api/moss/purchase) e registre no SQL.
  6. Replicar avisos de abertura/fechamento via Multicast ou UGameplayMessageSubsystem.

Passo a Passo em Unreal Engine 5

  1. Adicione um DataTable com linhas de loot (Group, ItemId, Rates e opções) e um asset de horário (array de FDateTime).
  2. Implemente um UMossEventSubsystem que calcula o próximo horário, replica RemainTime e estado.
  3. No evento START, spawn do NPC Moss em coordenadas fixas e replicadas.
  4. No NPC, processe a interação chamando ServerRollLoot; role um item com FRandomStream e crie o item no inventário do player.
  5. Envie eventos para HUD (contagem e avisos) e, opcionalmente, para backend HTTP (registro de compras e itens entregues).
  6. Teste com clients conectados: verificar countdown, spawn, entrega de item e limpeza ao fim do timer.
