Módulo 7 – Conexões JoinServer/DataServer

Detalhamos como o GameServer sobe e mantém conexões com serviços auxiliares (JoinServer e DataServer).

Pré-requisitos

  • Módulos 1 e 2 concluídos.
  • Conhecimento de sockets WinSock e mensagens de janela (FD_READ/FD_WRITE).

Conceitos do Código Original

Abertura de conexões – JoinServerConnect/DataServerConnect
📘 O Que é?

Funções que abrem sockets para os servidores auxiliares e enviam o pacote inicial de identificação.

🎯 Para Que Serve?

Permite que o GameServer registre-se e troque dados de contas/personagens com JoinServer e DataServer.

💻 Como Funciona?

bool JoinServerConnect(DWORD wMsg) {
    if(gJoinServerConnection.Connect(gServerInfo.m_JoinServerAddress,(WORD)gServerInfo.m_JoinServerPort,wMsg) == 0) {
        return 0;
    }
    GJServerInfoSend();
    return 1;
}

bool DataServerConnect(DWORD wMsg) {
    if(gDataServerConnection.Connect(gServerInfo.m_DataServerAddress,(WORD)gServerInfo.m_DataServerPort,wMsg) == 0) {
        return 0;
    }
    GDServerInfoSend();
    return 1;
}

⏱️ Quando é Executado?

Chamado logo após GameMainInit para estabelecer comunicação antes de aceitar jogadores.

Processamento de mensagens de socket – JoinServerMsgProc/DataServerMsgProc
📘 O Que é?

Handlers de eventos de socket que respondem a FD_READ, FD_WRITE e FD_CLOSE.

🎯 Para Que Serve?

Garante envio/recebimento de pacotes e encerra conexões limpidamente.

💻 Como Funciona?

void JoinServerMsgProc(WPARAM wParam,LPARAM lParam) {
    switch(LOWORD(lParam)) {
        case FD_READ: gJoinServerConnection.DataRecv(); break;
        case FD_WRITE: gJoinServerConnection.DataSendEx(); break;
        case FD_CLOSE:
            gJoinServerConnection.Disconnect();
            gObjAllDisconnect();
            break;
    }
}

⏱️ Quando é Executado?

Chamado pelo loop de mensagens Win32 do servidor sempre que o socket sinaliza atividade.

Implementação em Unreal Engine 5

Em um servidor dedicado UE5, encapsule as conexões auxiliares em um USubsystem iniciado pelo AGameModeBase.

UCLASS()
class UMuBackendSubsystem : public UGameInstanceSubsystem {
    GENERATED_BODY()
public:
    virtual void Initialize(FSubsystemCollectionBase& Collection) override {
        // Abrir sockets para Join/Data servers
    }
    virtual void Deinitialize() override {
        // Fechar sockets
    }
    void Tick(float DeltaTime);
};

Passo a Passo em Unreal Engine 5

  1. Criar um UGameInstanceSubsystem para manter sockets persistentes.
  2. Implementar callbacks de leitura/escrita usando FUdpSocketReceiver ou FTicker para simular o FD_READ.
  3. Enviar mensagem de identificação ao estabelecer conexão, espelhando GJServerInfoSend/GDServerInfoSend.
  4. Em caso de FD_CLOSE equivalente, derrubar sessões de jogadores como gObjAllDisconnect().

Checklist Final

  • Servidor UE5 conecta automaticamente a serviços auxiliares no boot.
  • Loop de recebimento envia e lê pacotes sem bloquear o game thread.
  • Desconexões forçam logout dos jogadores conectados.
