Módulo 55 – Enums de UI, Texturas e Estados de Janela

Reúne todos os enums de UI, índices de bitmaps e estados de janelas do cliente legado C++ para guiar a reconstrução 1:1 das telas na Unreal Engine 5, usando os assets convertidos (OZP/OZT/OZJ → PNG/TGA).

Enums e Catálogos do Código Legado

Índices de Textura (_TextureIndex.h)

O arquivo Source Main 5.2/source/_TextureIndex.h define blocos de índices para cada atlas:

  • UI base: BITMAP_INTERFACE_BEGIN … BITMAP_INTERFACE_END (janelas de inventário, warehouse, shop, status, trade).
  • Buff/UI específica: BITMAP_NEWBUFF_BEGIN … BITMAP_NEWBUFF_END, BITMAP_BUFFWATCH_MAINFRAME_BEGIN.
  • Eventos: BITMAP_BATTLESOCCER, BITMAP_SIEGEWAR, BITMAP_CHAOSCASTLE, blocos para Cursed Temple/Imperial Guardian.
  • MiniMapa e nome de mapa: BITMAP_MAPNAME, BITMAP_MINIMAP, usados em UIMapName e NewUIMiniMap.

Esses índices são carregados com LoadBitmap na inicialização da UI e referenciados em cada janela via coordenadas de recorte.

Estados de Janela e Input

Vários headers definem enums para o estado das janelas e botões:

  • UIMapName.h: enum SHOW_STATE { HIDE, FADEIN, SHOW, FADEOUT } controla a animação do nome do mapa.
  • ServerSelWin.h e ServerGroup.h: enums para posições e estados de botões (servidores ativos, bloqueados, em manutenção).
  • NewUIChatInputBox.h: enums INPUT_MESSAGE_TYPE e INPUT_TOOLTIP_TYPE definem o roteamento de chat/tooltip.
  • UIGateKeeper.h e UIGuardsMan.h: enums de abas e estados de registro de eventos (Siege/Guard).

Esses enums dirigem as máquinas de estado de input/renderização no cliente C++ e precisam ser espelhados em Blueprints.

Replicação 1:1 na Unreal Engine 5

  1. DataTable de Texturas UI: Crie DT_UITextures com colunas Index (Name), Atlas (Texture2D), UV (Vector4), Size (Vector2D), Description. Preencha usando os blocos de _TextureIndex.h (ex.: Interface.Inventory_BG, Buff.NewBuff_Frame, Event.ChaosCastle).
  2. Enum Blueprint E_UITextureId: Crie entradas que correspondam aos índices do legado e utilize Switch on E_UITextureId em widgets para recuperar UV/atlas com Get Data Table Row.
  3. Widgets com estados de janela: Replique SHOW_STATE com uma enum Blueprint E_ShowState e animações em Timeline: FadeIn (0→1 opacidade), Show (1), FadeOut (1→0). Aplique em WBP_MapName, WBP_ServerSelect e WBP_EventGate.
  4. Server Select e botões: Para ServerSelWin, crie um WBP_ServerSelect com grid 3×3. Cada célula consulta DT_ServerStates (ServerId, Status=Online/Busy/Down, Tooltip) e pinta o botão (verde/amarelo/vermelho) conforme os enums do legado.
  5. Chat/Input: No WBP_ChatInput, adicione enum E_InputMessageType (Normal, Party, Guild, Ally, Global) e E_InputTooltipType. Use OnTextCommitted → Switch on E_InputMessageType para roteamento (módulo 31).
  6. Gate Keeper / Guards: Crie WBP_GateKeeper e WBP_GuardsMan com tabs enumeradas conforme os headers (Registro, Status, Recompensas). Use Widget Switcher e Set Active Widget Index ligado a um Switch on E_GateKeeperTab.
  7. Conversão de assets: Converta os atlas OZP/OZT/OZJ para PNG/TGA preservando a ordem dos índices. Importe como Texture2D em /Game/MU/UI/Atlas e configure Compression Settings = UserInterface2D, Filter=Nearest, SRGB=true. Preencha o DT_UITextures com UVs correspondentes aos recortes usados no C++.

Checklist Final

  • Todos os índices de _TextureIndex.h convertidos para DT_UITextures e acessíveis via E_UITextureId.
  • Animações SHOW_STATE replicadas nos widgets que exibem nomes de mapa, seleção de servidor e eventos.
  • Estados de botões/abas (GateKeeper, GuardsMan, Chat) mapeados para enums Blueprint com Switch explícitos.
  • Atlas UI convertidos e importados com configuração de UI 2D, mantendo recortes e posições idênticas ao cliente legado.
