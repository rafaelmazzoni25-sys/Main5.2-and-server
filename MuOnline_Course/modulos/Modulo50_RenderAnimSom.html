Módulo 50 – Renderização, Animações e Sons Legados

Mapeia flags de renderização, ações e sons do cliente C++ para DataTables, Blueprints e assets na Unreal Engine 5, garantindo fidelidade 1:1.

Conceitos do Código Original

Flags e estrutura BMD (ZzzBMD.h)
📘 O Que é?

Arquivo que define o formato BMD, incluindo limites (MAX_BONES, MAX_MESH, MAX_VERTICES), flags de render (RENDER_CHROME, RENDER_WAVE, RENDER_NODEPTH, RENDER_BYSCRIPT) e ações (Action_t com PlaySpeed e LockPositions).

🎯 Para Que Serve?

Controla como modelos e animações são desenhados: brilho cromado, ondulação, efeitos adicionais, além da cadência das animações em BMD::Actions.

💻 Como Funciona?
  • Flags RENDER_* combinam bits para materiais especiais (cromado, óleo, wave).
    #define RENDER_CHROME 0x00000004 / #define RENDER_WAVE 0x00000400 etc.
  • Action_t contém PlaySpeed e LockPositions; as ações são indexadas no array Actions e são lidas por BMD::PlayAnimation para calcular AnimationFrame.
  • MAX_MONSTER_SOUND define 10 slots de som por BMD, preenchidos pelo cliente e disparados conforme a ação.
📁 Onde Encontrar?

Source Main 5.2/source/ZzzBMD.h

⏱️ Quando é Executado?

Carregado ao abrir BMDs do personagem, monstros e efeitos; usado por renderização/sons em todo o runtime.

IDs de som (DSPlaySound.h)
📘 O Que é?

Tabela de constantes numéricas para cada efeito de áudio: passos, UI, golpes, skills, eventos.

🎯 Para Que Serve?

Garante que cada ação/skill use o som correto e que o player tenha feedback idêntico ao cliente legado.

💻 Como Funciona?
  • Índices de ambiente (0–23), UI (25–42), ataque (60–70), efeitos (80–97), skills (111–133), especiais (140–159) e NPCs (160–210).
  • Os índices são associados aos slots do BMD::Sounds[MAX_MONSTER_SOUND] e disparados conforme animação.
📁 Onde Encontrar?

Source Main 5.2/source/DSPlaySound.h

⏱️ Quando é Executado?

A cada evento de UI (click, erro), movimento (passos por tipo de terreno) e execução de skill.

Passo a Passo – UE5 (Blueprints, DataTables, Assets)

  1. DataTable de animações por modelo: Crie DT_AnimMap (RowName = BMDName). Colunas: ActionIndex, ActionName, Montage (Soft Object), PlaySpeed, bLockPositions, SoundId, RenderFlags. Preencha usando os índices de ação do BMD original (ex.: MONSTER01_WALK, MONSTER01_ATTACK1).
  2. Material presets para flags: Crie materiais M_Chrome, M_Wave, M_Oil em /Game/MU/Materials. Nas Material Instances (ex.: MI_Wave_Sword), habilite World Position Offset para ondular (seno de tempo) e Reflections para cromado. Mapeie o bitfield RenderFlags → escolha do preset.
  3. Sound Cue DataTable: Monte DT_SoundMap com colunas SoundId, SoundCue, Category. Preencha com os IDs de DSPlaySound.h (ex.: 29 = UI_GetItem, 70 = Attack01, 116 = Storm, 152 = LevelUp).
  4. BP_ActionResolver: Crie Blueprint BP_ActionResolver (Object) com função ApplyRenderAndAudio(BMDName, ActionIndex, SkeletalMesh, AudioComponent). Nós: Get Data Table Row (DT_AnimMap) → Switch on RenderFlags → Set Material do mesh com o preset; Get Data Table Row (DT_SoundMap) → Set Sound no AudioComponent → Play.
  5. AnimInstance: No AnimBP do personagem/mob, adicione evento OnActionChanged(ActionIndex). Chame Play Montage com o Montage retornado da DT_AnimMap e, no AnimNotify “PlayStep”/“PlaySwing”, invoque BP_ActionResolver.ApplyRenderAndAudio para manter sincronia.
  6. Skills 3D (BMD → Niagara): Para skills com modelos (ex.: Spirit, Evil Spirit), importe o FBX e crie um Niagara System NS_Skill_Spirit. Adicione Mesh Renderer com material preset conforme RenderFlags. Use NS parameter User.SoundId para buscar SoundCue via DT_SoundMap e tocar no AudioComponent do sistema.
  7. Skills 2D (texturas OZ*/DDS): Converta OZJ/OZT/OZP/OZB/OZD para PNG/TGA/DDS. Crie Flipbook em Paper2D ou Niagara Sprite com Image Sequence. Adapte orientação (inverta Y se necessário) para alinhar ao eixo da UE5.
  8. Referenciamento de nível/excelente: Na tabela DT_ItemAssets (mód. 5), adicione colunas LevelMaterial (array de MI por nível) e ExcellentMaterial. No BP_MuCharacter, quando Item.Level > 0, troque para LevelMaterial[Item.Level]; se Item.Excellent == true, aplique ExcellentMaterial (preset com fresnel/scroll UV) antes do render.
  9. Validação 1:1: Crie um mapa de debug com três manequins e um mob; para cada ActionIndex, acione manualmente e compare frame-rate (PlaySpeed) e som disparado com o cliente legado. Ajuste PlaySpeed na DT_AnimMap até coincidir.

Checklist Final

  • Todos os BMDs possuem entrada em DT_AnimMap com PlaySpeed, SoundId e RenderFlags.
  • Presets de material para RENDER_CHROME, RENDER_WAVE e RENDER_NODEPTH aplicados em runtime.
  • Sounds de passos, UI, ataque, skill e eventos mapeados em DT_SoundMap e disparados por AnimNotifies.
  • Skills 3D/2D importadas (FBX/PNG) com orientação corrigida e áudio sincronizado.
  • Materiais de nível e excelente aplicados em equipamentos, reproduzindo o brilho/glow do cliente original.
