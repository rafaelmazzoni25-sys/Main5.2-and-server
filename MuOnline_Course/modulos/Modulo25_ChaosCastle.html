CChaosCastle::Load – Horários e tabelas de XP/Recompensa
📘 O Que é?

Lê ChaosCastle.dat e popula tempos de aviso, início, fechamento e tabelas de experiência/reward por nível.

void CChaosCastle::Load(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript->SetBuffer(path) == 0) { ... return; }
    this->m_ChaosCastleStartTime.clear();
    memset(this->m_ChaosCastleExperienceTable,0,sizeof(...));
    while(true) {
        if(lpMemScript->GetToken() == TOKEN_END) break;
        int section = lpMemScript->GetNumber();
        while(true) {
            if(section == 0) { this->m_WarningTime = lpMemScript->GetNumber(); this->m_NotifyTime = lpMemScript->GetAsNumber(); this->m_EventTime = lpMemScript->GetAsNumber(); this->m_CloseTime = lpMemScript->GetAsNumber(); }
            else if(section == 1) { CHAOS_CASTLE_START_TIME info; info.Year = lpMemScript->GetNumber(); info.Month = lpMemScript->GetAsNumber(); info.Day = lpMemScript->GetAsNumber(); info.DayOfWeek = lpMemScript->GetAsNumber(); info.Hour = lpMemScript->GetAsNumber(); info.Minute = lpMemScript->GetAsNumber(); info.Second = lpMemScript->GetAsNumber(); this->m_ChaosCastleStartTime.push_back(info); }
            else if(section == 2) { int level = lpMemScript->GetNumber(); this->m_ChaosCastleExperienceTable[level][0] = lpMemScript->GetAsNumber(); this->m_ChaosCastleExperienceTable[level][1] = lpMemScript->GetAsNumber(); }
            else if(section == 3) { int level = lpMemScript->GetNumber(); this->m_ChaosCastleRewardValue[level][0] = lpMemScript->GetAsNumber(); this->m_ChaosCastleRewardValue[level][1] = lpMemScript->GetAsNumber(); this->m_ChaosCastleRewardValue[level][2] = lpMemScript->GetAsNumber(); }
            else { break; }
        }
    }
}

🎯 Para Que Serve?

Configura tempo de preparação, início e fechamento do evento e parametriza quanto XP/prêmio cada nível concede ao vencedor.

💻 Como Funciona?

Processa seções numéricas do script, convertendo-as para listas internas de horários e tabelas de XP/reward, depois usadas no ciclo do evento.

CChaosCastle::MainProc – Ciclo de estados por nível
📘 O Que é?

Loop que percorre os 7 níveis, verifica tempo decorrido e avança estados (Blank/Empty/Stand/Start/Clean), controlando entrada e vitória.

void CChaosCastle::MainProc() {
    for(int n=0;n < MAX_CC_LEVEL;n++) {
        CHAOS_CASTLE_LEVEL* lpLevel = &this->m_ChaosCastleLevel[n];
        DWORD elapsed = GetTickCount()-lpLevel->TickCount;
        if(elapsed < 1000) { continue; }
        lpLevel->TickCount = GetTickCount();
        switch(lpLevel->State) {
            case CC_STATE_BLANK: this->ProcState_BLANK(lpLevel); break;
            case CC_STATE_EMPTY: this->ProcState_EMPTY(lpLevel); break;
            case CC_STATE_STAND: this->ProcState_STAND(lpLevel); break;
            case CC_STATE_START: this->ProcState_START(lpLevel); break;
            case CC_STATE_CLEAN: this->ProcState_CLEAN(lpLevel); break;
        }
    }
}

🎯 Para Que Serve?

Atualiza temporizadores de cada nível, libera entrada na fase Stand, inicia combate na fase Start e encerra com limpeza/recompensa.

💻 Como Funciona?

Usa TickCount para cadenciar em 1s; delega para ProcState_* que verificam limites de players/monstros e aplicam recompensas conforme tabelas carregadas.

Implementação em Unreal Engine 5

  • Estruturas equivalentes: AGameModeBase para controlar estados por nível; AGameStateBase replicado com arrays de tempos/premiações; APlayerController para pedidos de entrada; ULevelStreamingDynamic para instanciar arenas por nível.
  • Carregue horários e prêmios via DataTable (CSV/JSON) e aplique-os a um componente gerenciador no GameMode.
  • Implemente RPC ServerRequestEnterChaos(int32 Level) validando tickets, nível e lotação; em caso de sucesso, teleporte o jogador para o sub-level correspondente.
  • Cadencie estados com FTimerHandle e repasse via multicast ClientUpdateChaosState(Level, State) para UI.
  • Ao finalizar, distribua XP/itens replicados e registre resultado via VaRest em um endpoint Node.js/SQL para ranking/log.

Passo a Passo em Unreal Engine 5

  1. Definir FChaosCastleConfig (horas, tempos, XP, prêmios) e criar DataTable.
  2. Criar AChaosCastleGameMode com vetor de estados; iniciar timers de Stand/Start/Clean baseados na config.
  3. Adicionar componente de inventário que valide ticket do nível e exponha função para consumo.
  4. Implementar ServerRequestEnterChaos e teleporte para sub-level usando ServerTravel ou TeleportTo em arenas carregadas por streaming.
  5. Replicar contagem de jogadores/monstros via GameState; atualizar UI em tempo real.
  6. Aplicar recompensa e XP via GameMode ao detectar vencedor; chamar VaRest para registrar resultado em Node.js/SQL.
  7. Testar fluxo completo: aviso, abertura, início, vitória, fechamento e limpeza.

Checklist Final

  • Tempos de aviso/início/fechamento iguais ao ChaosCastle.dat carregados e aplicados.
  • Entrada validada por nível com ticket consumido e teleporte correto.
  • Estados Stand/Start/Clean replicados para UI e sincronizados entre clientes.
  • Recompensas de XP/itens distribuídas conforme tabelas e registradas em backend Node.js/SQL via VaRest.
  • Limpeza da arena executada e pronta para o próximo ciclo.

Tutorial Blueprint (clique a clique para iniciantes)

  1. No Content Browser crie uma pasta /ChaosCastle/ e adicione um DataTable do tipo FChaosCastleConfig. Campos mínimos: Level (0-6), WarningTime, NotifyTime, StandDuration, StartDuration, CleanDuration, XpReward, ItemRewardID, ItemRewardCount.
  2. Crie um Blueprint Class > GameModeBase chamado BP_ChaosCastleGameMode. No Event BeginPlay:
    1. DataTable Row → carregue todas as linhas para um Array variável Configs.
    2. Para cada config, faça Set Timer by Event (looping) de 1s para chamar TickChaos(Level).
  3. Dentro de BP_ChaosCastleGameMode adicione função TickChaos(Level):
    1. Recupere State e ElapsedSeconds (variáveis por nível em um Map<int, FChaosLevelState>).
    2. Use Switch on EChaosState (Blank, Stand, Start, Clean). Para Stand → se ElapsedSeconds >= StandDuration então chame EnterStart(Level). Para Start → se ElapsedSeconds >= StartDuration então EnterClean(Level). Para Clean → se ElapsedSeconds >= CleanDuration então EnterEmpty(Level).
    3. Após cada avanço, dispare Multicast MC_OnChaosState(Level, State, Remaining) (evento custom replicado) para UI.
  4. Implemente evento RPC ServerRequestEnterChaos no PlayerController:
    1. Valide ticket em Inventory (array replicado). Se não houver item TicketChaos(Level), retorne ClientFail("Ticket ausente").
    2. Cheque lotação via GameState->PlayersByLevel[Level].Length < MaxPlayers.
    3. Consuma ticket (remova item e salve via VaRest POST /api/chaos/ticket com accountId, level, consumed=true).
    4. Teleporte para Sub-Level: carregue /ChaosCastle/Levels/L_LevelX com Load Stream Level e use TeleportTo em um PlayerStart_LevelX.
  5. HUD para iniciantes: crie Widget WBP_ChaosHUD com 3 blocos fixos (ancoragem centro superior).
    1. Bloco Timer (ancho 420x60, posição X=760, Y=20): texto "Chaos Castle L{Level} - {State}" e barra de progresso com Remaining/Total.
    2. Lista de jogadores (300x200, X=20, Y=120) com ScrollBox; cada item mostra nome e classe. Alimente com OnRep_PlayersByLevel do GameState.
    3. Bloco Recompensa (280x120, X=20, Y=340) exibindo XpReward e ícone do item (use DataTable Row para ícone).
  6. Persistência VaRest/SQL:
    1. Ao finalizar nível (dentro de EnterClean), chame VaRest Request (POST) /api/chaos/finish com JSON { level, winnerAccount, winnerClass, xp, itemId, itemCount, timestamp }.
    2. No sucesso, aplique XP local (AddExperience) e GiveItem replicado.
    3. Em caso de falha HTTP, refile uma fila local (Array PendingReports) e tente reenviar a cada 5s com SetTimer.
  7. Debug visual:
    1. Crie widget WBP_ChaosDebug (250x160, ancorado no canto inferior direito X=1620, Y=840) com labels para State, Players, Monsters.
    2. Adicione botão Forçar Próximo Estado que chama RPC ServerDebugAdvance(Level) (protegido por flag bIsGM).
  8. Teste guiado:
    1. Simule relógio: diminua StandDuration e StartDuration para 10s em uma linha do DataTable para ver ciclos rápidos.
    2. Entre com 2 clientes, valide replicação do estado e teleporte correto.
    3. Desconecte a rede do host por 3s durante VaRest finish para ver retry da fila e confirmar persistência após reconexão.
