Conceitos do Código Original

ProtocolCore – despacho principal
📘 O Que é?

Função central do GameServer que analisa o cabeçalho (head) e chama o handler apropriado para cada tipo de pacote.

🎯 Para Que Serve?

Organiza a lógica de rede do servidor em um único ponto, garantindo logging e segurança antes de atingir subsistemas (ataque, movimento, itens).

💻 Como Funciona?

void ProtocolCore(BYTE head,BYTE* lpMsg,int size,int aIndex,int encrypt,int serial) {
    if((head != 0xF3 || lpMsg[3] != 0xF1) && head != 0x0E && head != 0x18 && head != PROTOCOL_CODE1) {
        char String[1024];
        for( int i = 0; i < size; ++i ) {
            sprintf(&String[2*i], "%02X", lpMsg[i]);
        }
        LogAdd(LOG_RED,"PacketIN: INDEX: %d TYPE: %#X, HEAD: %#04X, SIZE: %02d, PACKET: %s",aIndex,lpMsg[0],head,size,String);
    }
    switch(head) {
        case 0x00: CGChatRecv((PMSG_CHAT_RECV*)lpMsg,aIndex); break;
        case PROTOCOL_CODE2: gAttack.CGAttackRecv((PMSG_ATTACK_RECV*)lpMsg,aIndex); break;
        case PROTOCOL_CODE3: CGPositionRecv((PMSG_POSITION_RECV*)lpMsg,aIndex); break;
        case 0x19: gSkillManager.CGSkillAttackRecv((PMSG_SKILL_ATTACK_RECV*)lpMsg,aIndex); break;
        case 0x22: gItemManager.CGItemGetRecv((PMSG_ITEM_GET_RECV*)lpMsg,aIndex); break;
        // ... muitos outros cases
    }
}

Implementação em Unreal Engine 5

Em UE5, implemente roteamento em um UObject dedicado no servidor que mapeia códigos para delegates.

UCLASS()
class UMuPacketRouter : public UObject {
    GENERATED_BODY()
public:
    void RoutePacket(uint8 Head, const TArray& Data, int32 ClientId) {
        switch(Head) {
            case 0x00: HandleChat(Data, ClientId); break;
            case 0x19: HandleSkillAttack(Data, ClientId); break;
            case 0x22: HandleItemGet(Data, ClientId); break;
            default: break;
        }
    }
};

Passo a Passo em Unreal Engine 5

  1. Criar um objeto roteador (UMuPacketRouter) e instanciá-lo no AGameModeBase do servidor dedicado, armazenando referência ao socket.
  2. Converter structs de pacotes para USTRUCT() e desserializar antes de chamar handlers, validando tamanho mínimo e máximo de cada mensagem.
  3. Registrar logs de entrada em um canal semelhante a LogAdd, incluindo hex dump de pacotes incomuns para análise.
  4. Implementar handlers de chat, movimento, skills e itens usando classes APlayerController e ACharacter; delegar persistência ao módulo de inventário/persistência.
  5. Adicionar middleware de segurança para rejeitar pacotes com tamanho fora do esperado e bloquear IP/session em caso de flood, inspirado nas checagens de ProtocolCore.
  6. Encapsular métricas de contagem de pacotes por tipo para detecção de flood e publicar via HTTP (Node.js + SQL) para observabilidade.
  7. Escrever testes de integração que enviam pacotes binários gravados do servidor original e validam roteamento em UE5, incluindo casos de mensagens inválidas.
  8. Documentar cada ID de pacote em um UEnum exposto a Blueprints para depuração visual e criar um painel que mostra quantos pacotes por segundo estão chegando.
  9. Adicionar hot-reload de handlers: um mapa de delegates que permita substituir lógicas em runtime para testes A/B.

Guia Blueprint passo a passo (roteador visual)

Objetivo: montar um roteador de pacotes no UE5 só com Blueprints, com indicadores visuais e logs hexadecimais.

  1. No Content Browser, crie Blueprint Class → Actor chamado BP_PacketRouter. Marque Replicates.
  2. No Event BeginPlay, adicione:
    • Create Socket (UDP ou TCP conforme sua stack) e guarde em variável ClientSocket.
    • Bind Event to OnMessage → crie evento OnPacket.
  3. No evento OnPacket:
    • Use Get Bytes (do plugin) → Array Slice para separar Head (byte 0) e Body (restante).
    • Faça Switch on Int com os códigos principais (0x00 chat, 0x19 skill, 0x22 item, 0xC1 login etc.).
    • Para cada case, chame Custom Event correspondente: HandleChat, HandleAttack, HandleMove, HandleItem.
    • Adicione Print String para o hex dump: use Array To String e Replace para formatar "AA BB CC". Mostre no Screen e no Log.
  4. Para HandleChat: converta Body em texto via Byte Array To String (UTF-8) e repasse para um Multicast OnChatMessage em GameState. Exiba em um widget BP_ChatBox com ScrollBox.
  5. Para HandleMove: leia 2 bytes para X e 2 para Y (Array Slice + Bytes To Int). Chame Find Player By ID (mapa PlayerId → Character ref) e use Set Actor Location com RInterp To para suavizar.
  6. Para HandleAttack: desserialize TargetId e SkillId, verifique cooldown com Map de timestamps e chame Multicast PlayMontage no personagem.
  7. Para HandleItem: divida o corpo em Slot, ItemId, Durability; atualize BP_InventoryWidget chamando Set Brush From Texture no slot correspondente e salve estado em SaveGame.
  8. Crie um painel de depuração rápido: Widget BP_PacketHUD com 4 barras horizontais (ProgressBar) que mostram pacotes/s por tipo. No Tick do roteador, atualize as barras usando contadores incrementados em cada handler.
  9. Teste prático para iniciantes: use Simulate e dispare manualmente evento OnPacket com arrays pré-gravados (crie DataTable Packets.csv). Marque caixa de seleção "Passei" após ver o resultado em tela.
