Módulo 68 – Cinematics, Loading Scene e Direção de Câmera

Conecta o fluxo de entrada (Winmain → LoadingScene → MoveMap) com cutscenes e direções (CDirection, MovieScene, CKANTURUDirection, CMVP1stDirection). Define como replicar as animações introdutórias, tela de loading e controle de câmera no UE5 com Sequencer/Niagara.

Contexto do Código Legado

  • LoadingScene.cpp: renderiza plano com barra de progresso enquanto pré-carrega mapas, texturas e BMD.
  • CDirection.cpp / CKANTURUDirection.cpp: scripts de direção com keyframes para câmeras, eventos de som e disparo de partículas.
  • MovieScene.cpp: controla cenas de logotipo/intro e transição para a UI de login.

Blueprints e Sequencer

  1. Loading: crie WBP_Loading (Canvas 1920x1080) com barra de progresso (ProgressBar PB_Load em X=360,Y=900,W=1200,H=36) e dicas rotativas (Txt_Tip). O Level Blueprint de LV_Loading seta SetInputModeUIOnly e Show Mouse Cursor = false.
  2. Sequencer de Intro: em LV_Intro, adicione um Level Sequence SEQ_LogoIntro com faixas: CameraCut (FOV 45), plano de fundo (logo estático), fade-in/out (Track de Visibility). Duração 6s, chamando OpenLevel para LV_Login ao terminar.
  3. Direção de mapa: para mapas com scripts (Kanturu, MVP1st), crie Level Sequence por cena (SEQ_KanturuIntro, SEQ_MVP1st) com keyframes de posição/rotação da câmera replicando arrays de CDirection. Use CameraActor com InterpTo entre pontos e Play no BeginPlay do mapa.
  4. Eventos de som e FX: converta entradas de DSPlaySound.h usadas em cutscenes para AnimNotify ou Sequence Event Track. Para partículas (fog, spark), referencie Niagara NN_CutsceneSpark, NN_CutsceneFog e gatilhe via Spawn System at Location.
  5. Transição para gameplay: após SEQ_LogoIntro e WBP_Loading, carregue o mapa alvo via OpenLevel ou ServerTravel preservando o PlayerState. Ao concluir LV_Loading, spawn o pawn e chame AttachToController.

Recriação 1:1 da Tela de Loading

  • Imagens: use a arte legada Loading01-06 convertida para PNG/TGA em /UI/Loading. Alternar a cada 2s com Set Timer by Event.
  • Progressão: exponha um evento OnLoadingStep(percent, tip) chamado pelo GameInstance conforme cada asset/carregamento de mapa termina, espelhando o LoadingScene::LoadingProgress.
  • Orientação: no C++ a câmera é fixa; em UE5 mantenha a UI pura (sem 3D) e use render scale 1.0 para evitar blur.

Checklist

  • Sequências criadas para Intro e mapas especiais, com keyframes baseados em CDirection e eventos de som equivalentes.
  • WBP_Loading com barra e dicas em coordenadas exatas; troca de artes de fundo implementada.
  • Transições entre Intro → Login → Loading → Mapa preservam PlayerState e rotas de rede.
  • FX/sons das cutscenes mapeados para Niagara/SoundCue com gatilhos no Sequencer.
