Módulo 67 – UI Framework, Mensageria e Telas de Sistema

Mapeia as janelas legadas (LoginWin, CharSelMainWin, NewUICommandWindow, NewUIChatLogWindow, NewUIParty/Guild/Friend/Quest/Help/Option) e as adapta para UMG em UE5 com nomes de widgets, anchors e coordenadas 1:1. Centraliza o fluxo de abertura/fechamento controlado por CNewUIManager e callbacks de input (UIManager.cpp, NewUIManager.cpp).

Contexto do Código Legado

  • Registradores: cada janela é registrada em CNewUIManager::AddUIObj com um ID enum (INTERFACE_LOGIN, INTERFACE_INVENTORY, INTERFACE_COMMUNICATION_UI, INTERFACE_PARCHEMENT). Os callbacks de input e render ficam no loop principal (UIManager::RenderFrame).
  • Mensageria: caixas de mensagem (CBTMessageBox, NewUICustomMessageBox) usam filas para eventos síncronos e assíncronos. Chat, comandos e notificações passam por NewUIChatInputBox e NewUICommandWindow.
  • Fonts e números: CGFxFontConfigParser e NewUIRenderNumber carregam atlas de números e fontes GFX. Precisamos mapear para FontAssets/UMG usando RichText.

Fluxo de Input e Abertura

  1. PlayerController: em BP_MuPlayerController, crie um Input Map para teclas (Enter para chat, V para opções, H para ajuda, P para party, G para guild, F para friend, Q para quest). Cada input chama ToggleWidget correspondente.
  2. Router de UI: crie um componente BP_UIRouter anexado ao PlayerController com um Map<Enum_InterfaceID, WidgetClass>. No BeginPlay, instancie e oculte todos os widgets e registre em um UIStack para modalização.
  3. Mensagens e filas: implemente EnqueueMessage(MessageData) e DequeueMessage() para alimentar WBP_MessageBox. Use Timer by Event para auto-close conforme o legado (Timeout em segundos).
  4. Fonts/Números: converta atlas GFX para FontAssets; em widgets numéricos (dano, zen, score), use WBP_NumberRender com HorizontalBox e imagens de dígitos (64x96) ou RichText com fonte monoespaçada para preservar kerning.
  5. Sequência de abertura: defina na GameInstance uma ordem: Login → Servidores → CharSelect → LoadingScene → HUD. Replique o state machine do legado armazenando o CurrentInterface (enum) e notificando o UIRouter.

Checklist para Este Módulo

  • Todos os widgets criados nos caminhos indicados, com âncoras e tamanhos exatos.
  • Input bindings configurados no PlayerController seguindo os atalhos do código (NewUIHotKey).
  • Fila de mensagens (MessageBox) funcional com tempo de expiração e botões primário/secundário.
  • Chat/Log com cores e canais; comandos prefixados (/, ~, !, @) roteados para funções adequadas.
  • Help/Options/Hotkeys replicando árvores de texto e sliders de configuração equivalentes ao legado.
