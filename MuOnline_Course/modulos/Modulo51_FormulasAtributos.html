Módulo 51 – Fórmulas de Atributos, Dano e Resistências

Reproduz as fórmulas do cliente/servidor C++ para atributos base, escalas de monstro, cálculo de dano/defesa e desgaste (durabilidade), garantindo 1:1 em UE5.

Conceitos do Código Original

Escala de monstros e atributos iniciais
📘 O Que é?

MonsterConvert escala atributos de monstros pelo nível e CreateClassAttributes define os atributos base de cada classe jogável.

🎯 Para Que Serve?

Garante que monstros e personagens iniciem com valores idênticos ao cliente legado (velocidade de ataque, dano, defesa, bloqueio).

💻 Como Funciona?
  • MonsterConvert define AttackSpeed e escala dano/defesa/ataque/bloqueio proporcional ao nível do monstro (metade base + metade × Level/9).
  • CreateClassAttributes preenche Strength/Dexterity/Vitality/Energy/Life/Mana por classe (Dark Wizard, Knight, Elf, Magic Gladiator, Dark Lord, Summoner, Rage Fighter).
📁 Onde Encontrar?

Source Main 5.2/source/ZzzInfomation.cpp (MonsterConvert e CreateClassAttributes).

⏱️ Quando é Executado?

Na carga de scripts de monstros e na criação/reset de personagem.

Cálculo de dano por classe (CHARACTER_MACHINE::CalculateDamage)
📘 O Que é?

Fórmula de dano mínimo/máximo por mão, variando conforme classe e arma (arco/besta vs. melee).

🎯 Para Que Serve?

Preserva a curva de dano 1:1 do cliente C++ (ex.: Elf usando arco depende de Dexterity, Knight escala com Strength, Dark Lord combina Strength/Energy).

💻 Como Funciona?
  • Se arco/besta equipado e com durabilidade: Dexterity/7 + Strength/14 para dano mínimo; Dexterity/4 + Strength/8 para dano máximo.
  • Para cada classe: Elf usa (Strength+Dexterity)/7 e /4; Knight usa Strength/6–7 e /4; Dark Wizard mistura Strength/Energy; Dark Lord usa Strength/7 + Energy/14; Rage Fighter soma Strength/7 + Vitality/15 etc.
  • Valores finais são aplicados a AttackDamageMin/Max de cada mão.
📁 Onde Encontrar?

Source Main 5.2/source/ZzzInfomation.cpp (CalculateDamage).

⏱️ Quando é Executado?

Ao recalcular atributos (login, equip/unequip, distribuição de pontos).

Durabilidade e penalidade visual
📘 O Que é?

CalcDurabilityPercent calcula o desgaste e devolve offsets visuais (0.5/0.3/0.2/0) para representar itens quebrados.

🎯 Para Que Serve?

Define quando um item reduz glow ou mostra rachaduras no cliente; também orienta mensagens de reparo.

💻 Como Funciona?
  • Aumenta o máximo de durabilidade conforme nível (até +2 por bloco de 8 níveis).
  • Adiciona +20 se item for Set (ExtOption A/B) ou +15 se tiver option normal.
  • Retorna 0.5/0.3/0.2/0 conforme percentual gasto (>80%, >70%, >50%, caso contrário).
📁 Onde Encontrar?

Source Main 5.2/source/ZzzInfomation.cpp (CalcDurabilityPercent).

⏱️ Quando é Executado?

Ao renderizar itens no cliente e ao aplicar penalidades de durabilidade.

Seleção de opções Excellent no servidor
📘 O Que é?

CItemExOptionRate::GetExcellentOptionByRate sorteia quais bits Excellent entram em um item, evitando duplicidade e respeitando ranges por item.

🎯 Para Que Serve?

Garante que a geração de itens (drop/chaos mix) aplique opções Excellent com as mesmas probabilidades do servidor legado.

💻 Como Funciona?
  • Lê ItemExOptionRate.txt e armazena (ItemMinIndex/ItemMaxIndex, OptionIndex, OptionRate).
  • Ao sortear, ignora opções já presentes em NewOption e adiciona entradas na RandomManager para o range do item.
  • Devolve OptionIndex escolhido, que será aplicado ao item.
📁 Onde Encontrar?

Source MuServer Update 15/GameServer/GameServer/ItemExcellentOptionRate.cpp.

⏱️ Quando é Executado?

Na criação de item (drop, mix, reward) no servidor.

Passo a Passo – UE5 (Blueprints e DataTables)

  1. DataTable de classes: Crie DT_ClassBaseStats com colunas Strength/Dexterity/Vitality/Energy/Life/Mana/LevelLife/LevelMana/VitalityToLife/EnergyToMana/Shield. Preencha com os valores de CreateClassAttributes na mesma ordem.
  2. DataTable de escala de monstros: Crie DT_MonsterScale (RowName = MonsterType). Colunas: AttackSpeed, AttackDamageMin/MaxBase, DefenseBase, AttackRatingBase, BlockBase. Fórmula em Blueprint: Scaled = Base/2 + Base/2 * Level / 9, aplicada no spawn.
  3. BP_StatCalculator: Blueprint Function Library com CalcDamageForClass(Class, Strength, Dexterity, Energy, Vitality, bHasBow, bHasCrossbow). Use Select por classe para replicar as fórmulas de CalculateDamage (ramos específicos para Elf/bow, Knight, Dark Wizard, Dark Lord, Summoner, Rage Fighter).
  4. Aplicação de dano por mão: No BP_MuCharacter, ao atualizar atributos ou equipar, chame CalcDamageForClass e grave nos atributos replicados AttackDamageMinRight/MaxRight/MinLeft/MaxLeft. Usem Set Members in Struct na struct de atributos replicados.
  5. Durabilidade visual: No Widget de inventário, adicione função GetDurabilityPenalty(ItemData) replicando CalcDurabilityPercent (clamp de durabilidade, +20 se Set, +15 se option > 0; thresholds 0.8/0.7/0.5). Use o retorno para trocar material do ícone (ex.: cinza/rachado) e bloquear equip se retorno > 0.
  6. Sortear opção Excellent: Importe ItemExOptionRate.txt para um DataTable DT_ExcellentRate. Crie BP_ExcellentPicker com função PickExcellent(ItemIndex, ExistingBits): filtra linhas pelo range do item, ignora bits já presentes, usa Select Random Weighted com OptionRate e devolve o bit escolhido, igual ao GetExcellentOptionByRate.
  7. Sincronismo cliente/servidor: No servidor dedicado UE5, salve atributos calculados em AMuPlayerState (replicated). No cliente, use OnRep para atualizar UI (HUD e tooltips) e manter valores idênticos ao pipeline legado.
  8. Validação 1:1: Crie mapa de teste com dummies de cada classe e um monstro nível 10. Compare valores de dano/defesa/ASPD exibidos com os do cliente legado (usando tabelas exportadas). Ajuste constantes no DataTable até igualar.

Checklist Final

  • Todos os monstros aplicam a escala Base/2 + Base/2*(Level/9) e mantêm AttackSpeed original.
  • Classes usam fórmulas específicas (Elf com arco = Dex/7+Str/14, Knight = Str/6-7, Dark Lord = Str/7+Energy/14, Rage Fighter = Str/7+Vit/15 etc.).
  • Ícones e modelos de item respondem à durabilidade com materiais alternativos.
  • Itens Excellent sorteiam bits via tabela ponderada idêntica à do servidor.
  • HUD/Status exibem atributos replicados do servidor dedicado, sem divergência.
