🎯 Para Que Serve?

Controla dinamicamente quanto XP cada personagem recebe conforme level, reset e master reset, permitindo regras diferentes por faixa.

💻 Como Funciona?

Em GetExperienceRate e GetMasterExperienceRate o servidor percorre a lista carregada e seleciona o primeiro intervalo compatível com Level, Reset e MasterReset, retornando o multiplicador ou 100% por padrão.

int CExperienceTable::GetExperienceRate(LPOBJ lpObj) {
    for(auto it : this->m_ExperienceTableInfo) {
        if(it.MinLevel != -1 && it.MinLevel > lpObj->Level) continue;
        if(it.MaxLevel != -1 && it.MaxLevel < lpObj->Level) continue;
        if(it.MinReset != -1 && it.MinReset > lpObj->Reset) continue;
        if(it.MaxReset != -1 && it.MaxReset < lpObj->Reset) continue;
        if(it.MinMasterReset != -1 && it.MinMasterReset > lpObj->MasterReset) continue;
        if(it.MaxMasterReset != -1 && it.MaxMasterReset < lpObj->MasterReset) continue;
        return it.ExperienceRate;
    }
    return 100;
}

⏱️ Quando é Executado?

Load é chamado na inicialização do GameServer (carregamento de scripts). GetExperienceRate/GetMasterExperienceRate são invocados durante o cálculo de XP ao matar monstros ou completar eventos, dentro das rotinas de recompensa que consultam a tabela antes de aplicar experiência ao jogador.

// uso típico dentro de rotinas de reward
int rate = gExperienceTable.GetExperienceRate(lpObj);
int gain = baseExp * rate / 100;

Implementação em Unreal Engine 5

Para espelhar a lógica, use um UDataTable com faixas de level/reset/master e um componente de progressão anexado ao APlayerState ou ACharacter.

  1. Crie um USTRUCT FExperienceRow com campos MinLevel, MaxLevel, MinReset, MaxReset, MinMasterLevel, MaxMasterLevel, MinMasterReset, MaxMasterReset e ExperienceRate; salve em um DataTable via CSV/JSON.
  2. Implemente um UActorComponent UProgressionComponent com funções GetRate() e GetMasterRate() que percorrem o DataTable reproduzindo os mesmos filtros do código original.
  3. Ao aplicar XP (em AGameMode ou APlayerState), obtenha o multiplicador do componente e multiplique a recompensa antes de atualizar atributos; use MarkDirtyForReplication para replicar o novo XP.
  4. Persistência: exponha endpoint Node.js (/xp/update) que grava XP/reset/master em SQL; consuma via VaRest no cliente ou faça RPC servidor → HTTP.
  5. Teste com valores extremos: faixas com -1 (ilimitado), resets elevados e master resets para garantir que o iterador encontra o primeiro intervalo válido, como no servidor.

Passo a Passo em Unreal Engine 5

  1. Gerar DataTable ExperienceTable em Content/Data/ExperienceTable.csv replicando colunas do script original.
  2. Adicionar UProgressionComponent ao APlayerState, carregando o DataTable em BeginPlay do servidor.
  3. Implementar ApplyExperience(int32 BaseExp) no APlayerState: consultar o componente, aplicar multiplicador, atualizar XP/Level/Reset/Master e disparar eventos OnLevelUp.
  4. Integrar com UI: criar widget com barras de XP e texto de reset/master, atualizados por bindings do APlayerState.
  5. Persistir: no OnLogout do APlayerController servidor, chamar VaRest → Node.js → SQL para salvar Level, Reset, MasterLevel, MasterReset, garantindo idempotência.
  6. Automatizar testes: criar comandos de console xp.give, xp.reset e validar faixas com valores de teste equivalentes aos do script.

Checklist Final

  • DataTable de experiência carregado e aplicado no servidor UE5.

  • Persistência via VaRest/Node.js/SQL salva e restaura progression.
  • Comandos de debug garantem que faixas com -1 (sem limite) funcionam.
