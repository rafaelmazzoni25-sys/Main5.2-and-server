Documenta a configuração e validação dos itens 380, incluindo leitura de opções, checagem de flag 0x80 e aplicação de valores, com roteiro completo para replicar na UE5.

Pré-requisitos

  • Módulo 5 – Inventário/Itens.

Conceitos do Código Original

Leitura de Opções 380 – C380ItemOption::Load/SetInfo
📘 O Que é?

Rotina que carrega de script as opções dos itens 380 e as armazena no array m_380ItemOptionInfo.

void C380ItemOption::Load(char* path) {
    CMemScript* lpMemScript = new CMemScript;
    if(lpMemScript == 0) { ErrorMessageBox(MEM_SCRIPT_ALLOC_ERROR,path); return; }
    if(lpMemScript->SetBuffer(path) == 0) { ErrorMessageBox(lpMemScript->GetLastError()); delete lpMemScript; return; }
    this->Init();
    try {
        while(true) {
            if(lpMemScript->GetToken() == TOKEN_END) break;
            if(strcmp("end",lpMemScript->GetString()) == 0) break;
            ITEM_380_OPTION_INFO info; memset(&info,0,sizeof(info));
            info.Index = lpMemScript->GetNumber();
            strcpy_s(info.Name, lpMemScript->GetAsString());
            info.Value = lpMemScript->GetAsNumber();
            this->SetInfo(info);
        }
    } catch(...) { ErrorMessageBox(lpMemScript->GetLastError()); }
    delete lpMemScript;
}

void C380ItemOption::SetInfo(ITEM_380_OPTION_INFO info) {
    if(info.Index < 0 || info.Index >= MAX_380_ITEM_OPTION) return;
    this->m_380ItemOptionInfo[info.Index] = info;
}

🎯 Para Que Serve?

Habilita opções únicas para itens 380, definindo valores por índice que serão aplicados ao equipar.

💻 Como Funciona?

O script define nome/valor por índice. Load preenche o array, e outras rotinas consultam GetInfo para aplicar bônus. Qualquer índice inválido é ignorado.

Validação de Itens 380 – C380ItemOption::Is380Item
📘 O Que é?

Checagem que confirma se um item possui a flag 380 (m_ItemOptionEx & 0x80).

🎯 Para Que Serve?

Impede aplicação indevida de bônus 380 a itens que não possuem o bit de opção estendido.

💻 Como Funciona?

Verifica o bit 0x80 em m_ItemOptionEx e retorna false caso não esteja setado.

bool C380ItemOption::Is380Item(CItem* lpItem) {
    if((lpItem->m_ItemOptionEx & 0x80) == 0) {
        return 0;
    }
    // demais validações seguem ...
}

Implementação em Unreal Engine 5

Use um DataTable de opções 380 e um componente de itens que verifica a flag estendida antes de aplicar bônus.

  1. Crie USTRUCT FItem380OptionRow com Index, Name, Value; importe do script.
  2. Adicione ao UItemDefinition um campo bHas380Flag que corresponde a m_ItemOptionEx & 0x80.
  3. No UInventoryComponent, implemente Apply380Options() que percorre os itens equipados, verifica bHas380Flag e consulta o DataTable para aplicar modificadores (ex.: AttributeSet no GAS).
  4. Persistência: sincronize o bit e os índices via Node.js/SQL; para segurança, valide no servidor UE5 se o item recebido realmente tem bHas380Flag antes de aplicar bônus.
  5. UI: destaque itens 380 com ícone ou cor; inclua tooltip exibindo Name e Value vindos do DataTable.
  6. Testes: scripts automatizados que equipam/unequipam itens 380 e verificam aplicação/remoção de atributos replicados.

Passo a Passo em Unreal Engine 5

  1. Importar o script 380 em Content/Data/Item380.csv para um DataTable de FItem380OptionRow.
  2. Adicionar campo bHas380Flag às definições de item (DataAsset/DataTable) e preencher conforme banco legado.
  3. No servidor UE5, ao equipar um item, verificar a flag; se verdadeira, consultar o DataTable e aplicar modificadores no AttributeSet.
  4. Persistir bHas380Flag e índice da opção em SQL via Node.js, acionado por VaRest quando o inventário é salvo.
  5. Criar testes de regressão: troca rápida de equipamentos 380, reconexão (para garantir re-aplicação), e verificação de segurança contra itens sem flag.

Guia detalhado para iniciantes

  1. Tabela: adicione colunas SetName, PartsNeeded, DefBonus, AtkBonus, SocketCount em Item380.csv. Importe como FItem380Row.
  2. Componente: crie BP_Item380Component no PlayerState com arrays replicados Equipped380 (ItemID, SetName, SocketValues) e funções RecalcBonus/ApplySocketEffects.
  3. Equipar: no evento OnItemEquipped do InventoryComponent, se bHas380Flag for true, insira no array e chame RecalcBonus. Aplique modificadores (GameplayEffect) de defesa/ataque conforme tabela e, se EquippedCount == PartsNeeded, aplique FullSetBonus.
  4. Sockets: cada item contém SocketValues (array int). UI WBP_Item380 mostra 5 círculos de 20px logo abaixo do slot (offset Y = +28). Clique em um círculo abre WBP_SocketPicker que grava o valor e chama ApplySocketEffects.
  5. VaRest: POST /item380/save com {account, items:[{id,set,sockets[]}]} sempre que OnItemEquipped/Unequipped ocorre. No login, GET /item380/load e re-popule Equipped380 antes do primeiro RecalcBonus.
  6. Testes: cenário A (2 peças) deve mostrar bônus parcial; cenário B (conjunto completo) ativa FullSet. Remova uma peça e confirme que bônus completo some. Reentre para validar que sockets e flags persistem.

Checklist Final

  • DataTable de opções 380 carregado no UE5.
  • Itens trazem flag 0x80 persistida e validada.
  • Bônus 380 aplicados/retirados corretamente em equipar/desequipar.
  • Persistência via VaRest/Node.js/SQL sincroniza flag e opções.
  • UI exibe claramente que o item é 380 e mostra seus valores.
