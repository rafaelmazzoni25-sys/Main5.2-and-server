Módulo 0 – Auditoria do Legado e Escopo

Este módulo amarra cada tópico do curso ao que realmente existe nos fontes Source Main 5.2 e Source MuServer Update 15. Ele sinaliza quais temas têm suporte explícito no C++ legado e quais precisam ser implementados do zero na UE5.

Funcionalidades confirmadas no legado

  • Inventário de Evento (EventInventory.cpp/EventInventory.h) está presente no DataServer e no GameServer, com buffers EventInventory1/EventInventory2, slots e salvamento/recuperação de itens temporários.
  • OffAttack/OffStore aparecem no GameServer (contadores globais e taxas em ServerInfo.cpp), portanto os módulos de operação offline devem usar essas estruturas já existentes.

Funcionalidades ausentes nos fontes fornecidos

Não há referências a estas features no código legado; qualquer implementação em UE5 será nova e deve ser tratada como tal:

  • Gremory Case: nenhum símbolo ou arquivo com “Gremory” foi encontrado. O módulo 72 deve ser seguido como blueprint de recriação, não como porte literal.
  • MU Helper/Auto-Hunt: não há Helper/AutoHunt no cliente ou servidor do pacote fornecido. O módulo 63 descreve um desenho compatível, mas não deriva de código existente.

Como usar esta auditoria

  • Quando um módulo for marcado aqui como “ausente”, mantenha a fidelidade visual e comportamental desejada, mas documente claramente que se trata de implementação inédita.
  • Para módulos confirmados, referencie os arquivos listados para extrair lógica, enums, estruturas e fluxos de rede antes de adaptar aos Blueprints/UMG.
  • Atualize esta página sempre que uma nova checagem identificar (ou refutar) a presença de funcionalidades do legado.
