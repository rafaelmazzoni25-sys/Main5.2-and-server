Como usar esta auditoria

  • Quando um módulo for marcado aqui como “ausente”, mantenha a fidelidade visual e comportamental desejada, mas documente claramente que se trata de implementação inédita.
  • Para módulos confirmados, referencie os arquivos listados para extrair lógica, enums, estruturas e fluxos de rede antes de adaptar aos Blueprints/UMG.
  • Nos módulos híbridos (ex.: 72), separe as seções “legado” e “fora do legado” no próprio HTML para não misturar instruções novas com o porte 1:1.
  • Se não desejar adicionar features novas (ex.: MU Helper), simplesmente ignore o módulo ou marque-o como “desabilitado” no sumário do projeto UE5.
  • Atualize esta página sempre que uma nova checagem identificar (ou refutar) a presença de funcionalidades do legado.
