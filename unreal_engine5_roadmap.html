Roadmap integral

Passo a passo para portar o cliente Source Main 5.2 e os serviços Source MuServer Update 15 para Unreal Engine 5+

Cada fase abaixo referencia diretórios e arquivos reais (ex.: source/BoneManager.*, GameServer/GameServer/BloodCastle.*) para garantir rastreabilidade entre o código legado e os novos módulos em UE5. Use os botões para carregar instruções exatas de implementação, checklist e comandos sugeridos.

Objetivo

Paridade funcional + modernização UE5/Netcode

Stack final

  • Unreal Engine 5.4 (C++ + Blueprints)
  • Pixel Streaming + HTTP/JSON bridge
  • gRPC/REST para integrações com novos serviços

Fontes analisadas

  • Cliente: Source Main 5.2/source/*.cpp
  • Servidores: Source MuServer Update 15/*/*.cpp
  • Ferramentas: FerramentasExport/, MuServer_Season_5_Update_15/

Fase 0

Auditoria e preparação

Inventarie dependências Win32/DX9, assets e protocolos. Extraia diagramas de source/ e GameServer/ usando clang-scan + scripts Python do diretório FerramentasExport.

Fase 1

Fundamentos do cliente UE5

Migre o núcleo de renderização (ex-DirectX: BlackWin.*, Builder.*) para UGameInstance, UGameViewportClient e Enhanced Input. Configure streaming levels equivalentes ao CSMapServer.*.

Fase 2

UI, HUD e inventário

Recrie janelas Win32 (Button.*, CBTMessageBox.*, CGFxMainUi.*) com UMG/Slate, Data Assets e CommonUI. Aproveite dados_blueprint_dashboard.* como referência visual.

Fase 3

Personagens e gameplay

Portar CharacterManager.*, BoneManager.*, CSPetSystem.* e lógicas de eventos (CSChaosCastle.*) para componentes UE5 replicados.

Fase 4

Servidores dedicados

Refatore módulos de GameServer/GameServer (ex.: BloodCastle.*, CastleSiege.*, CashShop.*) em microserviços Unreal ou C++17 standalone com protocolo gRPC.

Fase 5

QA, operações e hand-off

Automatize builds (Unreal Build Tool + GitHub Actions), monitore métricas e valide protocolos com Source MuServer Update 15/Util.

Serviços & Ops

Fonte: Source MuServer Update 15/*

  • Reescrever módulos GameServer em microserviços
  • Sincronizar DataServer/JoinServer com UE5
  • Automatizar CI/CD e monitoramento
  1. Preparação do projeto UE5: criar workspace monorepo (pastas Source Main 5.2, Source MuServer Update 15, ProjetoUnrealEngine), configurar Git LFS para assets e gerar documentação automática via clang-scan-deps e Doxygen.
  2. Base do cliente: instanciar classes UGameInstance, UGameViewportClient, APlayerController e mapear inputs dos arquivos CDirection.*, CameraMove.* e BlackWin.* para Enhanced Input e Subsystems.
  3. Interface e HUD: traduzir Button.*, CGFxMainUi.*, CharMakeWin.* e CharSelMainWin.* para widgets UMG/Slate, utilizando Data Assets derivados de dados_blueprint_dashboard.* para manter consistência visual.
  4. Inventário e itens: converter estruturas de CSParts.*, CSItemOption.*, ItemExcellentOption.* em UDataTables, criar UInventoryComponent replicado e conectar RPCs às chamadas do novo JoinServer/DataServer.
  5. Personagens e gameplay: importar rigs do diretório source/Character usando Control Rig, portar CharacterManager.*, BoneManager.*, CSPetSystem.* para componentes e reimplementar eventos (CSChaosCastle.*, BloodCastle.*, CastleSiege.*) como UWorldSubsystem + AGameMode dedicados.
  6. Rede: refatorar protocolos definidos em ConnectServer/Protocol.* e GameServer/GameServer/Command.* para uma camada unificada (HTTP para autenticação, UDP/TCP para gameplay), mantendo compatibilidade com clientes clássicos via parsers binários.
  7. Servidores dedicados: reescrever GameServer, DataServer, JoinServer e ConnectServer como microserviços C++17/gRPC; encapsular módulos (CashShop.*, ChaosBox.*, Command.*) em bibliotecas compartilhadas e expor APIs para o cliente UE5.
  8. Ferramentas e pipelines: portar utilitários de FerramentasExport/ para automatizar conversão de assets, configurar BuildGraph/Gauntlet/GitHub Actions e integrar telemetria (Prometheus/Grafana) usando dados de Util/LogProc.*.
  9. QA final: validar mapas, inventários e eventos replicando roteiros originais, armazenar registros no painel deste roadmap (export JSON) e preparar documentação final para hand-off.
