Estudo em microblocos

UE5.7 para TDAH: Blueprints primeiro, C++ depois

Use blocos de 10–20 minutos para praticar uma única micro-competência de cada vez. Quebre trechos de 3–10 nós (Blueprints) ou 3–10 linhas (C++) e responda: o que é, para que serve, onde usar, quando usar. Depois, faça uma variação mínima para consolidar.

Rotina recomendada: 1 foco por bloco • 3 blocos Blueprint → 2 blocos C++ • sempre mexer no código
Filtro rápido por módulo + nível

Escolha o que estudar agora

Digite parte do nome (ex.: Niagara, Material, Root) e selecione o nível que você quer atacar. Cada card traz um caminho de básico → intermediário → avançado em passos curtos.

Physical Animation

FísicaPersonagem
  • Básico: Adicione Physical Animation Component, ative simulação nos corpos principais e copie pose do mesh.
  • Intermediário: Faça blend por osso (torso/head) ajustando Angular Strength/Damping e use Set Strength Multiplyer via BP.
  • Avançado: Dirija força com curvas (ataque/impacto), sincronize com ragdoll parcial e teste replicação de pose.

Animation Montages

AnimCombate
  • Básico: Crie um Montage com seções (Start/Loop/End) e Notifies para evento.
  • Intermediário: Use Branching Points e Slots para diferenciar UpperBody vs FullBody; controle Play Rate.
  • Avançado: Sincronize com Root Motion, configure Montage Sync Groups e valide replicação (Multicast + Section Jump).

The Anim State Machine

AnimLocomoção
  • Básico: Monte Idle/Walk/Run com regras simples usando velocidade.
  • Intermediário: Introduza Cached Poses, Blendspaces 1D/2D e transições com “Rule from Result”.
  • Avançado: Sub-State Machines (Locomotion/Combat), sincronização por Sync Groups e tempo de transição data-driven.

Root Motion

AnimRede
  • Básico: Ative Enable Root Motion em sequências/montages e teste preview da trajetória.
  • Intermediário: Ajuste Root Motion Mode, combine com Root Motion Sources e alinhe com movimento do capsule.
  • Avançado: Valide em servidor dedicado (correção de posição) e integre com Distance Matching.

Blend Poses by Bool & Enum

AnimLayering
  • Básico: Use Blend Poses by Bool para alternar entre agachar/levantar com tempos de blend curtos.
  • Intermediário: Troque para Blend by Enum cobrindo Idle/Walk/Run/Sprint e ajuste Blend Weights.
  • Avançado: Controle pesos por Curve ou Data Table e exponha parâmetros via C++ para tuning in-game.

Niagara Particles

VFXNiagara
  • Básico: Crie sistema a partir de template, configure um emissor com taxa de spawn constante e cor.
  • Intermediário: Exponha parâmetros (User) para BP, adicione módulos de aceleração/drag e Ribbon quando aplicável.
  • Avançado: Use simulação em GPU, escalonamento (Scalability) e Niagara Fluids/FX que dependem de view distance.

Save Pose Snapshot

AnimRecuperação
  • Básico: Capture pose com Save Pose Snapshot e restaure com Use Cached Pose após um evento.
  • Intermediário: Transicione de ragdoll para animação suavizando com blend para o snapshot.
  • Avançado: Combine snapshot + Root Motion de um Montage curto para levantar e sincronize pela rede.

All Particle Spawners

VFXNiagara
  • Básico: Compare Spawn Rate, Burst e Event Generator em um único sistema.
  • Intermediário: Use eventos de colisão/impacto para acionar spawns secundários e Spawn per Unit para trails.
  • Avançado: Misture spawners GPU + CPU, gerencie LODs e use Determinism para previsibilidade.

MetaSounds

ÁudioProcedural
  • Básico: Crie um MetaSound Source simples (Osc → Envelope → Output) e toque em um Sound Cue.
  • Intermediário: Exponha parâmetros (pitch/volume) para BP, use Random Seed e filtros.
  • Avançado: Sincronize com Gameplay Cues, sidechain/ducking e snapshots de mix dinâmico.

Material Overlay

MateriaisShading
  • Básico: Faça um Lerp entre base color e cor de overlay usando máscara simples.
  • Intermediário: Use Material Layers/Blends para separar sujidade/danos.
  • Avançado: Dirija o overlay por Dynamic Parameter (HP, tempo) e valide custo no Shader Complexity.

Niagara Collisions

VFXColisão
  • Básico: Ative módulo de colisão com plano simples (floor) e visualize debug.
  • Intermediário: Ajuste Friction/Restitution, resposta a canais (Pawn/WorldStatic) e decal de impacto.
  • Avançado: Colisões GPU com Distance Fields ou Scene Depth e fallback em hardware fraco.

Material Functions

MateriaisReutilização
  • Básico: Crie função para tiling/UV e reutilize em materiais diferentes.
  • Intermediário: Adicione inputs (scalar/vector) para controlar intensidade e normal strength.
  • Avançado: Forme uma biblioteca de funções otimizadas (triplanar, cheap AO) e documente parâmetros.

Dynamic Lights

IluminaçãoPerformance
  • Básico: Configure Point/Spot lights como Movable e teste sombras dinâmicas.
  • Intermediário: Use Light Functions, IES profiles e limite o alcance com Attenuation.
  • Avançado: Gerencie custo (Max Draw Distance, Distance Fields/Virtual Shadow Maps) e LODs de luz.

Material Parameter Collection

MateriaisSistemas
  • Básico: Crie uma MPC com scalar/vector e leia em material para alterar cor ou emissive.
  • Intermediário: Atualize MPC via Blueprint (ex.: carga de poder, clima) e propague para múltiplos materiais.
  • Avançado: Controle MPC por Timeline/Curve e combine com pós-processo para efeitos globais.

Motion Matching

AnimNext-Gen
  • Básico: Ative plugin, gere banco com animações de locomoção e teste no character BP.
  • Intermediário: Ajuste esquema de busca (trajetória, velocidade, tags) e debug no Pose Search.
  • Avançado: Integre com Stride Warping, transições de combate e validação em rede.

Parallax Occlusion Mapping

MateriaisDetalhe
  • Básico: Use nó Parallax Occlusion Mapping com heightmap simples.
  • Intermediário: Ajuste Height Ratio e Steps para equilíbrio entre detalhe e custo.
  • Avançado: Configure LOD/fallback para mobile e valide artefatos com sombras/distorções.

Parallax & Bump Decals

MateriaisDecal
  • Básico: Crie decal diferido com normal/roughness para marcas simples.
  • Intermediário: Use height blend para integrar decal ao solo e ajuste ordem/sort.
  • Avançado: POM em decal com máscara de opacidade e ajuste ângulo de fade para evitar estiramento.

Flow Maps

MateriaisUV
  • Básico: Importe flow map e combine com Panner para deslocar normal/color.
  • Intermediário: Mescle duas direções (lerp) para redemoinhos ou rios com curvas.
  • Avançado: Controle intensidade via Blueprint (chuva/vento) e otimize instruções.

Custom Niagara Modules

VFXCódigo
  • Básico: Duplique um módulo existente, altere uma variável e teste resultado.
  • Intermediário: Crie módulo em HLSL/Script para força customizada e exponha parâmetros.
  • Avançado: Organize numa Niagara Module Script Library, documente inputs e valide custo em GPU.
Aulas de reforço (10–20 min)

Complementos prontos para módulos já estudados

Use como sessões rápidas de revisão: objetivo claro, 3 passos e 1 variação para fixar. Misture com o filtro no topo para focar no módulo do dia.

MetaSounds

  • Objetivo: Criar um whoosh responsivo a velocidade de dash.
  • Passos: (1) Adicione Audio Velocity ou parâmetro User exposto; (2) use LFO rápido para modulação de pitch; (3) conecte em OnDash no BP.
  • Variação: Troque o LFO por envelope gatilhado por Gameplay Cue e compare curva de ataque.

Material Parameter Collection

  • Objetivo: Sincronizar cor de alerta em todos os materiais.
  • Passos: (1) Crie MPC com AlertColor; (2) leia no material de personagem e HUD; (3) altere via Timeline no GameMode.
  • Variação: Substitua Timeline por curva em Data Table para testar diferentes cadências.

Flow Maps

  • Objetivo: Dar vida a um rio curto em 15 minutos.
  • Passos: (1) Importe flow map e aplique em material com Panner; (2) misture duas direções com Lerp usando máscara pintada; (3) exponha velocidade via parâmetro.
  • Variação: Controle velocidade por Blueprint com base em volume de chuva (MPC) e veja resposta imediata.

Dynamic Lights

  • Objetivo: Criar luz de alarme móvel sem estourar performance.
  • Passos: (1) Instancie Spot Light Movable e anime rotação com Timeline; (2) limite Attenuation Radius e habilite IES; (3) habilite VSM ou DF para sombras limpas.
  • Variação: Troque VSM por sombras tradicionais e compare Stat GPU.

Parallax & Bump Decals

  • Objetivo: Impacto de projétil com decal profundo.
  • Passos: (1) Crie decal com normal/roughness + máscara de opacidade; (2) habilite Parallax Offset controlado por distância da câmera; (3) instancie via BP no local da colisão.
  • Variação: Desative Parallax além de 20m e veja fade suave no ângulo raso.

Niagara Collisions

  • Objetivo: Partículas que reagem a chão inclinado.
  • Passos: (1) Ative colisão por Scene Depth e visualize debug; (2) adicione decal no impacto com atraso; (3) exponha Restitution como parâmetro User.
  • Variação: Troque para colisão por Distance Field e compare bounce em superfícies curvas.

Motion Matching

  • Objetivo: Refinar curvas de custo para resposta mais ágil.
  • Passos: (1) Duplique banco de poses e altere pesos de trajetória vs velocidade; (2) ajuste Future Trajectory Samples; (3) valide no visor de debug.
  • Variação: Adicione tag de “Strafe” e observe clipes escolhidos ao mudar direção brusca.

Custom Niagara Modules

  • Objetivo: Criar módulo de vento direcional reutilizável.
  • Passos: (1) Crie Module Script com direção/força expostas; (2) normalize vetor e aplique em Update; (3) publique em pasta de biblioteca.
  • Variação: Adicione ruído perlin no módulo e compare jitter em CPU vs GPU.

Material Functions

  • Objetivo: Centralizar tiling com triplanar simples.
  • Passos: (1) Crie função triplanar com inputs de escala; (2) exponha normal strength e roughness; (3) aplique em dois materiais diferentes.
  • Variação: Substitua triplanar por world aligned blend para medir diferença de instruções.
Aulas guiadas por módulo

Roteiros prontos para blocos de 20–40 minutos

Use estes roteiros como “mini-aulas”: cada item indica objetivo, passos e uma variação rápida para fixar. Siga na ordem ou misture conforme o foco do dia.

Physical Animation

  • Aula 1 (Básico): Adicione Physical Animation Component, ligue no Mesh e acione Set Strength via BeginPlay. Variação: altere Orientation Strength de 50 → 150.
  • Aula 2 (Intermediário): Separe Body Name por osso (Torso, Head) e blende com animação normal. Variação: teste um Curve no Montage para reduzir força na parte final.
  • Aula 3 (Avançado): Configure ragdoll parcial, salve pose com Save Pose Snapshot e volte com blend controlado. Variação: replique o estado via Multicast e valide delay.

Animation Montages

  • Aula 1 (Básico): Crie seções Start/Loop/End, insira Anim Notifies para efeitos e toque via Montage Play. Variação: mude o Play Rate de 1.0 → 1.2.
  • Aula 2 (Intermediário): Use Branching Points para validar hitbox e slots Upper/Full Body. Variação: troque o slot do ataque para checar impacto na parte superior apenas.
  • Aula 3 (Avançado): Combine com Root Motion e Montage Sync Groups para coop/combate. Variação: force Section Jump remoto e veja sincronismo na rede.

Root Motion + State Machine

  • Aula 1 (Básico): Ative Root Motion numa animação de dash e visualize preview. Variação: altere o modo para Root Motion from Montages Only.
  • Aula 2 (Intermediário): Na State Machine, use Blend Poses by Bool para alternar locomotion/dash com tempos de blend curtos. Variação: teste Blend by Enum com Sprint.
  • Aula 3 (Avançado): Combine Root Motion Sources (Override vs Additive) e valide correção de posição em servidor dedicado. Variação: logue delta de posição entre client/servidor.

Anim State Machine

  • Aula 1 (Básico): Crie estados Idle/Walk/Run usando velocidade como condição. Variação: altere o limiar de Run 600 → 450.
  • Aula 2 (Intermediário): Adicione Sub-State para Combate e use Cached Poses para reutilizar Locomotion. Variação: teste regra “Evaluate Transition” com atraso de 0.1s.
  • Aula 3 (Avançado): Configure Sync Groups e Transition Sync para manter pés alinhados. Variação: mude o grupo de sync para UpperBody e valide efeito.

Blend Poses by Bool & Enum

  • Aula 1 (Básico): Use Blend Poses by Bool para alternar agachar/levantar com blend de 0.2s. Variação: troque para 0.05s e observe popping.
  • Aula 2 (Intermediário): Troque para Blend by Enum com estados Idle/Walk/Run/Sprint e pesos custom. Variação: altere peso do Sprint para 1.25.
  • Aula 3 (Avançado): Dirija pesos via curva em Data Table e exponha scalar para ajuste runtime. Variação: teste curvas diferentes para transição brusca vs suave.

Save Pose Snapshot

  • Aula 1 (Básico): Capture pose em um evento (ex.: queda) e restaure com Use Cached Pose. Variação: salve com 0.3s de atraso pós-impacto.
  • Aula 2 (Intermediário): Saia de ragdoll para em pé usando blend para o snapshot em 0.5s. Variação: teste 0.2s e veja estabilidade.
  • Aula 3 (Avançado): Combine snapshot com Root Motion de um Montage curto para levantar em rede. Variação: force replay do Montage se delta de posição for > 30cm.

Niagara Particles

  • Aula 2 (Intermediário): Exponha parâmetros User para cor/escala, adicione módulo de colisão simples e Ribbon. Variação: altere colisão para Scene Depth.
  • Aula 3 (Avançado): Crie módulo customizado (HLSL) para força direcional e teste em GPU com Scalability. Variação: adicione Spawn per Unit para um trail.

Começo rápido em Blueprints

Bloco 1 (10–15 min): input + movimento

  • O que é? Evento InputAction Move → nó Add Movement Input.
  • Para que serve? Transformar eixo WASD/analógico em deslocamento do CharacterMovement.
  • Onde usar? No BP derivado de Character ou Pawn.
  • Quando usar? Assim que o projeto estiver com Enhanced Input habilitado.
  • Variação: Troque a escala (0.5 → 1.2) ou inverta eixo Y para sentir o impacto.

Bloco 2: condição simples (branch)

  • O que é? Nó Branch + comparação Speed >= 200.
  • Para que serve? Escolher comportamento com base em velocidade.
  • Onde usar? No Tick ou na máquina de estados de animação.
  • Quando usar? Sempre que um estado depende de valor numérico.
  • Variação: Troque o limite para 300 e logue o resultado com Print String.

Bloco 3: replicação mínima

  • O que é? Variável bIsAttacking marcada como Replicated.
  • Para que serve? Garantir que a animação de ataque sincronize entre clientes.
  • Onde usar? BP do personagem ou Actor compartilhado.
  • Quando usar? Antes de adicionar FX/sons dependentes do servidor.
  • Variação: Adicione OnRep_bIsAttacking tocando um Niagara simples.
Do básico ao avançado em Blueprints

Escalada de assuntos (cada item = 1–2 blocos)

Fundamentos

  • Variáveis, Branch, For/While, Timers.
  • Interfaces Blueprint para desacoplar UI ↔ gameplay.
  • Componentes (Scene, Audio, Niagara) e hierarquias.

Intermediário

  • Animation Blueprint + State Machines (Idle/Walk/Run/Attack).
  • Data Tables para stats e descrições de itens.
  • UMG + Input Mode para Login/Inventário/HUD.

Avançado

  • Replicação customizada (Owner Only, Multicast para FX).
  • Ability System ou pattern de Gameplay Tags para buffs.
  • Profiling (Stat Unit, Stat Net) e otimização de Tick.
Transição para C++

Primeiro bloco (10–15 min): componente simples

Use o mesmo método: 3–10 linhas, 1 variação. O objetivo é entender a função de cada parte antes de expandir.

// Minimal: componente que registra entrada no log
#include "GameFramework/Actor.h"
#include "Components/ActorComponent.h"

class ULogOnceComponent : public UActorComponent
{
  GENERATED_BODY()
public:
  virtual void BeginPlay() override
  {
    Super::BeginPlay();
    UE_LOG(LogTemp, Log, TEXT("Actor: %s"), *GetOwner()->GetName());
  }
};
  • O que é? Classe C++ derivada de UActorComponent.
  • Para que serve? Anexar comportamento reutilizável sem duplicar Blueprints.
  • Onde usar? Em qualquer Actor/Character via Add Component.
  • Quando usar? Quando a lógica é chamada em muitos BPs (log, validação, cooldown).
  • Variação: Adicione um UPROPERTY(EditAnywhere) com string e logue o valor.
Evolução em C++ (blocos seguintes)

Básico

  • Construtores e PrimaryComponentTick (ativar/desativar Tick).
  • Funções BlueprintCallable para expor utilitários aos nós.
  • UFUNCTION(Server/Client/NetMulticast) para replicação.

Intermediário

  • Structs com UPROPERTY e Data Assets para configs.
  • Subsystems (GameInstance/World/LocalPlayer) para singletons claros.
  • Bindings de input em C++ usando Enhanced Input.

Avançado

  • Replicação manual de arrays/mapas usando FFastArraySerializer.
  • Plugins com módulos separados (Runtime/Editor) para tooling.
  • Tests funcionais (Automation Spec) para validar fluxos de rede.
