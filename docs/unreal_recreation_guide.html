Configuração Inicial

  1. Projeto Multiplayer UE5
    Abra a Unreal → New Project → Games → Blank → marque C++, Starter Content e Enable Multiplayer. Depois: Edit > Project Settings > Maps & Modes → defina Game Default Map para Login_P e marque Use Split Screen desativado. Em Engine > Network ative Enable Net Dormancy e deixe Use Dedicated Server ligado para empacotar o servidor.
  2. Submódulos e Estrutura
    No Explorer/Finder crie Source/Server, Source/Client, Content/UI, Content/Data. Abra DefaultEngine.ini e force NetDriverDefinitions=(DefName="GameNetDriver",DriverClassName="/Script/OnlineSubsystemUtils.IpNetDriver",DriverClassNameFallback="/Script/OnlineSubsystemUtils.IpNetDriver"). Configure WorldSettings -> GlobalDefaultGameMode para AGM_ServerAuthoritative (classe C++ que você criará).
  3. Classes base
    Clique direito no Content Browser → C++ Class → derive: UGI_MMORPG (GameInstance), AGM_ServerAuthoritative (GameMode), APlayerStateRPG, APlayerControllerLobby, ACharacterRPG. Compile. Depois, clique direito → Blueprint Class → derive de cada uma para gerar BP_ equivalentes.
  4. Preparar mapas
    Crie mapas vazios Login_P, Lobby_P e Mundo_P. Em cada um, adicione PlayerStart, NavMeshBoundsVolume cobrindo o terreno e salve. No Level Blueprint de Login_P, em BeginPlay adicione Create Widget (classe WBP_Login) → Add to Viewport → Set Input Mode UI Only.

Cookbook rápido: sempre que mencionar “crie widget”, use Content Browser → User Interface → Widget Blueprint, dê o nome sugerido, abra e monte a hierarquia exatamente como descrito em cada seção.

Fórmulas & Tabelas (Server-Only)

Implemente as fórmulas exatamente como no C++ legado, usando funções server-side (RPC ou AbilitySystem) e replicando apenas os resultados.

XP / Level Up

A tabela original define gLevelExperience[n] = (((n+9)*n)*n)*10 e, para níveis acima de 255, soma ((over+9)*over*over)*1000. Configure uma CurveTable com essa curva (coluna XPToNext) e carregue no GameMode.

void UGI_MMORPG::BuildXpCurve(UCurveTable* Curve) {
  FRichCurve* CurvePtr = Curve->FindRichCurve(TEXT("XPToNext"), true);
  double Over = 1.0;
  for(int32 Level=1; Level<=MAX_LEVEL; ++Level) {
    const double Base = (Level+9)*Level*Level*10.0;
    const double Extra = (Level>255) ? ((Over+9)*Over*Over*1000.0) : 0.0;
    CurvePtr->AddKey(Level, Base+Extra);
    if(Level>255) { Over += 1.0; }
  }
}

No Blueprint do GameMode: em BeginPlay, carregue a CurveTable, salve em variável e use em uma função Server_GrantXP(PlayerState, DeltaXP) que consulta a curva e incrementa Level/NextExperience como no legado.【F:Source MuServer Update 15/GameServer/GameServer/User.cpp†L582-L598】

Chance de Acerto (MissCheck)

Replique a fórmula: AttackSuccessRate recebe bônus e multiplicadores, aplica divisores, e compara com DefenseSuccessRate. Em Blueprints (Function Library server-only):

  1. Inputs: AttackSuccessRate, DefenseSuccessRate, structs EffectOption de atacante/defensor.
  2. Somar AddAttackSuccessRate e multiplicar por MulAttackSuccessRate/100; subtrair divisão DivAttackSuccessRate; clamp a zero.
  3. Repetir para defesa (AddDefenseSuccessRate, MulDefenseSuccessRate, DivDefenseSuccessRate).
  4. Se ataque < defesa: 5% de acerto, senão role Rand % AttackSuccessRate < defesa para miss.

Implemente como BlueprintCallable ComputeHitResult e retorne um booleano e tag de efeito; conecte ao ApplyDamage antes de executar GAS GameplayEvent.【F:Source MuServer Update 15/GameServer/GameServer/Attack.cpp†L1903-L1933】

Dano Físico

Use a rotina GetAttackDamage: soma dano mínimo/máximo de cada mão, bônus de skill e multiplicadores de efeito; sorteia entre Min/Max; aplica crítico (100% do Max + bônus) e excelente (120% do Max). Subtrai a defesa do alvo no final.

int32 UCombatMath::CalcPhysicalDamage(const FCombatContext& Ctx) {
  int32 DamageMin = Ctx.PhysiMin + Ctx.SkillDamageMin;
  int32 DamageMax = Ctx.PhysiMax + Ctx.SkillDamageMax;
  DamageMin += Ctx.AddPhysiDamage + Ctx.AddMinPhysiDamage;
  DamageMax += Ctx.AddPhysiDamage + Ctx.AddMaxPhysiDamage;
  DamageMin = DamageMin + (DamageMin * Ctx.MulPhysiDamage) / 100 - (DamageMin * Ctx.DivPhysiDamage) / 100;
  DamageMax = DamageMax + (DamageMax * Ctx.MulPhysiDamage) / 100 - (DamageMax * Ctx.DivPhysiDamage) / 100;
  const int32 Roll = FMath::RandRange(0, FMath::Max(1, DamageMax - DamageMin));
  int32 Damage = DamageMin + Roll;
  if (FRand() * 100.f < Ctx.CritChance) { Damage = DamageMax + Ctx.CritBonus; }
  if (FRand() * 100.f < Ctx.ExcChance) { Damage = (DamageMax * 120) / 100 + Ctx.ExcBonus; }
  Damage -= Ctx.TargetDefense;
  return FMath::Max(0, Damage);
}

No Ability do ataque: calcule PhysiMin/Max somando mãos e skill (SwordPower) como no legado e depois subtraia TargetDefense. Use GameplayCue para efeitos 2=Excellent, 3=Critical conforme os bits (*effect).【F:Source MuServer Update 15/GameServer/GameServer/Attack.cpp†L2266-L2432】

Dano Mágico / Cursed

Para magias, acrescente m_DamageMin/m_DamageMax da skill, bônus do MasterSkillTree, SkillDamageBonus e multiplicadores de EffectOption; chance de crítico/excelente igual ao físico. Se usar arma mágica, aumente pelo MagicDamageRate do item.

No Blueprint, reproduza a lógica antes de aplicar ApplyDamage e suporte skills de carregamento como Nova adicionando (NovaConstA*(NovaCount*NovaConstB)) + (Strength/NovaConstC) ao dano base.【F:Source MuServer Update 15/GameServer/GameServer/Attack.cpp†L2435-L2472】

// Em APlayerStateRPG (RPC no servidor)
UFUNCTION(Server, Reliable)
void Server_AddExperience(int64 Delta)
{
    Experience += Delta;
    while (Experience + DeltaPending >= NextExperience)
    {
        Level++;
        LevelUpPoints += LevelUpPerClass[ClassId];
        if (Level > 220 && bQuest220Complete) { LevelUpPoints += PlusStatPoint; }
        DeltaPending = (Experience + DeltaPending) - NextExperience;
        RecalcNextExperience();
    }
    OnRep_Exp();
}

Blueprint: no PlayerState derive: Custom Event Server_AddExperience (RPC Server) → nó Add para Experience → WhileLoop com condição Experience >= NextExperience → dentro do loop: Increment Int Level, Add LevelUpPoints (use Select por classe), Branch para bônus >220, Subtract Experience -= NextExperience e chame função RecalcNextExperience.

Gameplay: Combate & Skills (Server Authoritative)

Fórmula de Dano Físico (legado)

Base: soma dano mínimo/máximo, aplica bônus de skill, efeitos adicionais, multiplicadores, rolagem aleatória e só então subtrai a defesa do alvo.【F:Source MuServer Update 15/GameServer/GameServer/Attack.cpp†L2266-L2300】

int32 ServerCalcPhysicalDamage(const FAttackCtx& Ctx)
{
    int32 DamageMin = Ctx.PhyMin + Ctx.SkillMin;
    int32 DamageMax = Ctx.PhyMax + Ctx.SkillMax;
    DamageMin += Ctx.AddPhys;
    DamageMax += Ctx.AddPhys;
    DamageMin += (DamageMin * Ctx.MulPhys) / 100;
    DamageMax += (DamageMax * Ctx.MulPhys) / 100;
    DamageMin -= (DamageMin * Ctx.DivPhys) / 100;
    DamageMax -= (DamageMax * Ctx.DivPhys) / 100;
    const int32 Roll = FMath::RandRange(DamageMin, DamageMax);
    const int32 Crit = (FMath::RandRange(0,99) < Ctx.CritRate) ? (DamageMax + Ctx.CritBonus) : Roll;
    const int32 Exc  = (FMath::RandRange(0,99) < Ctx.ExcRate)  ? ((DamageMax * 120 / 100) + Ctx.ExcBonus) : Crit;
    return FMath::Max(0, Exc - Ctx.TargetDefense);
}

Blueprint: no servidor, monte sequência: Add dano base + skill → Add bônus fixos → Multiply (int) por 1+MulPhys/100 → Subtract divisores → Random Integer in Range (Min, Max) → dois Branches para crítico/excelente (random < chance) → Subtract defesa → Max (Int) com 0.
